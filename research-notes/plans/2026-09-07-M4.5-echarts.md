# Plan 4.5 ECharts 受控组件 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 ECharts 收编为组件库受控组件 `<EChart>`——按需引入 + 主题生成器（token 同源、换主题自动跟随）+ 动效策略（本体 animation:false，出场动效走引擎）+ 门禁新条目（option 禁裸色/裸字体）。

**Architecture:** 主题生成器（tokens.css → ECharts theme 注册）保证 token 同源；EChart 组件统一 init/setOption/dispose/resize 生命周期；SVGRenderer 默认（jsdom 可测 + 渲染截图稳定）；章节层传 option 不写颜色字体（门禁扫描）。

**Tech Stack:** echarts ^5（按需引入 echarts/core + BarChart/LineChart/PieChart + GridComponent/TooltipComponent/LegendComponent + SVGRenderer）。

**Spec:** `../07-design-draft.md`（§12c Plan 4.5 路线图条目）。

## Global Constraints

- 主题生成器读 tokens.css（fs/模块级——与 token-scale 同源模式）生成 ECharts theme：系列色板 = [--accent-1, --accent-2, --accent-3, --accent-4]、坐标轴/网格线 = 墨/cream-2、文字 = Space Grotesk/Noto Sans SC、无圆角——**换主题自动跟随**
- **Ruling P4.5-1**：默认 SVGRenderer（jsdom 可测/门禁无头 pass 可 DOM 断言/渲染截图稳定）；CanvasRenderer 留未来大数据量选项
- **动效策略**：ECharts 本体永远 `animation: false`；图表出场动效由引擎入场动画提供（EChart 组件 reveal prop 走工厂/动画运行时——复用 createPrimitive？EChart 有自定义生命周期，reveal 用 motion.revealAnim 自接）
- 组件契约全套：统一出口/lint 护栏/smoke presence/styleguide 展示/卸载 dispose（echartsInstance.dispose()）
- 门禁新条目（M3a 扩展）：章节层 `<EChart option={...}>` 对象字面量内 color/textStyle.fontFamily 裸值 → blocker；var(--x) 豁免
- 门禁测试双护栏（负样本 + 非空护栏）
