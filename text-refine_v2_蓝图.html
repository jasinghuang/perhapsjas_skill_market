03

批次循环与重试阶梯

严禁整篇一次性生成 · 严禁逐条孤立翻译
material --batch N

生成材料：源条目 + duration_ms + max_units + sentence_group + flash 标记 + 术语锁 + 邻组上下文

→
agent 翻译

同组整句构思，按各条时长当量切片回填；只写 {id, 译文}

→
check --batch N

ID 恰好覆盖 · 非空（除 flash）· CPS / 行长分级 · 术语合规 · 组连续分区不变量

→
通过 → 合并

幂等写入 master draft，status.json 记进度

① 批级重试 ≤ 2 次

check 返回逐条错误（id + 违规项 + 实测值），agent 只修复被点名的条目

② 组级重试

仍失败的语义组单独重翻，携带更宽上下文

③ AskUserQuestion 升级

保留原文 / 人工供稿 / 放宽预算重试

阶梯尽头没有「跳过门禁」选项——质量下限不由模型自觉决定。

05

提示词与数据契约

模型看得见约束，才谈得上遵守约束
batch_material_N.json · 批次材料 Schema
"instruction": "<版本化模板渲染，哈希绑定>",
"target_lang": "zh",
"style_note": "创作者教程，自豪、利落、极客口语",
"glossary": [{"source": "Character Sheet", "target": "角色设定图"}],
"context": {"prev_group_source": "…", "next_group_source": "…",
            "prev_batch_tail_translation": "…"},
"items": [
  {"id": "entry-000001", "text": "Every single frame … you",
   "duration_ms": 2240, "max_units": 11, "sentence_group": "g001", "flash": false},
  {"id": "entry-000006", "text": "A",
   "duration_ms": 80, "max_units": null, "sentence_group": "g002", "flash": true}
]
max_units = max(2, floor(duration_s × 5))
软指导预算，单位为语速当量字；门禁只看 CPS 硬算，两层不叠加容差
sentence_group
Python 按句末标点 / 留白 ≥800ms 切组；同组必须整句构思再切片回填，禁止倒装直译
flash: true（<500ms）
无预算，允许空填、内容并入邻条；旧产物在 80ms 槽强填"如果是"（CPS≈37）即此策略由来
context 上下文携带
邻组源文静态携带；前批译文尾部动态注入（串行执行，并行批次 P2 且只带源文）
batch_draft_N.json · 输出契约（结构与内容分离）
{"items": [{"id": "entry-000001", "text": "你刚刚看到的那支音乐视频里的"}]}
  • 只回 id + 译文；时间戳、序号由 Python 独占，模型碰不到
  • 数组而非 {id: text} 字典——JSON 对象无序且重复键会静默覆盖
  • 单条单行；含空行 / "-->" / NUL 为阻塞错误

指令模板要点batch_template.md · 版本化

  • 同组整句语境翻译，按各条时长比例切片，断点落在标点 / 连词
  • 遵守 max_units 预算；英文词按当量计（K-pop = 2.0）
  • 术语表为锁死映射，不得改译；口吻按 style_note
  • flash 条目可留空，内容并入邻条
  • 标点遵循仓库标准：语义需要则保留，不为美观删标点

独立审校指令要点另一 agent · 信达雅

  • 先完整读 line-break-cases.md，再 review-input 取原文 + 带时间轴候选 + 阅读诊断 + 术语锁
  • 信事实 / 逻辑 / 数字 / 指代 · 达意群 / 断句 / 阅读负担 · 雅文体 / 口吻贴合题材
  • 不灌翻译者结论；coverage 顺序全覆盖；findings 带 severity
  • 四哈希绑定：源文件 / 稿件 / 最终候选 / 任务+引擎+模板，任一变更须重审
06

质量控制

三口径不混用 · 分级不放水
effective_units语速口径

管 CPS 门禁与 max_units 预算；纯汉字行当量 == 字数，既有阈值无缝沿用

汉字 1.0 · AI=2.0 · LLM=3.0 · K-pop=2.0
长词 max(2.5, len/3) · 4153=4.0
display_width排版口径

管行长门禁；修复 len() 把半角按全角计的口径混乱

全角 1.0 · 半角 0.5 → "K-pop" = 2.5 宽
visible_char_count纯外文行沿用

无汉字条目按 15~17 字符/秒参考，避免重校英文阈值

仅当 effective_units == 0 时生效

门禁分级

级别触发条件处置
阻塞条数 / ID / 时间戳变动 · 非 flash 空文本 · 结构泄漏 · 术语违规 · 当量 CPS >10 · 行长 >24直接失败进重试阶梯；审校无权放行
必修当量 CPS 7~10 · 行长 18~24 · flash 空填 · 单条 >6srequired finding，未 resolved 不得 finish
提示当量 CPS 5~7 · 行长 14~18 · 估算时间披露进审校视野，不强制

D5
约束进输入

批次材料必须带 duration_ms / max_units / sentence_group——修复"要求时间槽约束却不给时长"的矛盾

D6

D7
