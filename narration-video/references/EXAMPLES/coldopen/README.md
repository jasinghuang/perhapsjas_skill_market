# anchor：coldopen（财报反差开场）

**定位**：财报解读视频的开场章——用一个"最意外的数"砸出悬念，导出本章主线。
**适用**：任何"先给结论再展开"的财报叙事。

## 结构骨架（4 步）

| step | 干什么 | 主导动画词汇（示例） |
|---|---|---|
| 1 | 反差对撞：营收 +12.4% vs 净利润 -3.2% 两个 hero 数字并置，剪刀差一目了然 | `HeroNumber + DeltaText` |
| 2 | 规模锚点：营收 843 亿"什么概念"（同行/历史类比上画面） | `Counter`（数字滚到 843） |
| 3 | 悬念落点：净利润 98.7 亿与它的下滑——引入"为什么" | `BarGrow`（下滑柱体） |
| 4 | 收束：问题出在毛利率——引导进入下一章 | `MarkerBlock`（墨底砸结论） |

## 关键节奏决策（为什么这么切）

1. **第 1 步必须是"对撞"不是"铺垫"**——两个数并置比"先介绍公司"抓人十倍；
   剪刀差本身是内容（增收不增利），不是修辞
2. **第 2 步的感受锚点必须上画面**（口播念"什么概念"，画面放同行对比数字）——
   锚点是画面细节，不是口播感叹
3. **第 4 步的收束只挂结论不挂数据**——数据留给下一章展开；这一步的使命是"钩住"
4. **全章 4 步 ≈ 45-55 秒**——开场别长，悬念要在观众划走前给完

## 换题材时保留什么、换什么

| 保留（形） | 换（动作） |
|---|---|
| 四步结构：对撞 → 锚点 → 悬念 → 收束 | 对撞的数字换（营收vs利润 / 收入vs现金流 / 营收vs股价） |
| "第 1 步给最意外的数"这条纪律 | 组件换：对撞可用 `SplitCompare`；锚点可换 `StatCell` 群 |
| "收束只挂结论" | 悬念落点可换成风险提示（`PostIt`） |

> 反照抄纪律见 [../README.md](../README.md)——这是**结构骨架**，不是模板；
> 每一步的主导动画仍要走 CHAPTER-CRAFT 决策树 + Checkpoint 2 确认。
