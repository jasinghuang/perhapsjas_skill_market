# `outline.md` 格式 spec

视频章节规划的产出文件。**用户可以直接编辑**，所以格式必须人类友好
（markdown，不是 JSON/YAML）。

> ## ⚠️ outline 是开发计划，不是视觉规划
>
> outline 只规划**节奏 + 内容 + 信息密度**：
>
> - 章节切分 / 每章 step 数 / 每步估时
> - 每步屏幕内容（hero 数字 / 对比 / 表格行 / 风险点）
> - 章节级**信息池**（从财报/文章抽的数字 / 口径 / 风险句 / 出处页）
>
> **不写**：动画类型 / CSS 手段 / 时长数值 / 微观节奏（写死动画 = chapter
> agent 退化为翻译机）。**outline 里的 step 数是初始预估**——最终以机器生成的
> `narrations` 为准（真相源）；不一致时回同步 outline，不用纠结严丝合缝。

---

## 抽象示例（看格式）

```markdown
# Video Outline

> **主题**：creative-mode（Checkpoint 1 已选定）
> **总时长**：约 3 分 20 秒（口播 ~800 字 ÷ 4 字/秒）
> **章节数**：5 章 / 24 步

---

## 1. coldopen — 增收不增利（4 steps · ~55s）

**信息池**（chapter agent 按需挂角标 / 副标 / 对比卡 / 数据浮层）：
- 数字：营收 843.21 亿元，同比 +12.4% —— 来源 年报第 5 页 · 主要会计数据
- 数字：归母净利润 98.7 亿元，同比 -3.2% —— 来源 年报第 5 页
- 口径：同比 = 与上年同期相比；本报告期 = 2025 年度 —— 来源 年报第 3 页
- 对比：营收增速 12.4% vs 净利润增速 -3.2% 的剪刀差 —— 来源 自算（两数对比）

**开发计划**：

- step 1 (~12s) — 全场反差开场：营收 +12.4% vs 净利润 -3.2% 的剪刀差大数字对撞
- step 2 (~15s) — 营收 843 亿的规模锚点（"什么概念"类比）
- step 3 (~15s) — 净利润 98.7 亿与它的下滑（引入"为什么"悬念）
- step 4 (~13s) — 收束悬念：问题出在毛利率——引导进入下一章

口播节选：
> 先说最要紧的。营收 843 亿，同比增长 12.4%。但归母净利润不涨反跌……
```

> **关于时长**：只写 step 的 `(~Ts)` 口播估时（音画对齐用），**绝对不写**动画
> 时长/错峰量/缓动。那些在 Phase 4 决定（CHAPTER-CRAFT 的动画决策树）。

## 字段约定

### 顶部 metadata block

| 字段 | 必填 | 说明 |
|---|---|---|
| **主题** | ✓ | Checkpoint 1 必须已选定（v1 = creative-mode） |
| **总时长** | ✓ | 估算口播时长（中文 ~4 字/秒；财报节奏略慢可 ~3.5 字/秒） |
| **章节数** | ✓ | `N 章 / M 步` |

### 章节标题：`## N. <id> — <title>（<S> steps · ~<T>s）`

| 部分 | 规则 |
|---|---|
| `N` | 1-indexed 顺序，对齐 `src/chapters/manifest.ts` 的注册顺序 |
| `<id>` | **小写 + 连字符**。成为文件夹名（`src/chapters/0N-<id>/`）与音频子目录（`public/audio/<folder>/`，即 `0N-<id>/`） |
| `<title>` | 给人看的中文标题，**不进代码** |
| `<S> steps` / `~<T>s` | 该章 step 总数与口播总估时 |

合法 id：`coldopen`、`revenue-structure`。不合法：`why_good`（下划线）、`Hook`
（大写）、`第一章`（非拉丁）。

### 章节首段「信息池」（双源原则核心落地）

每章独立列出从**原始财报/文章**抽的细节集合，让 chapter agent 做画面时按需取用。
财报信息池的条目类型：数字 / 口径 / 对比 / 风险句 / 出处页 / 术语解释。

```
- <类型>：<具体内容> —— 来源 年报第 X 页 / 第 X 节
```

> **没有 article（用户直接给稿子）**：信息池退化为"主动设计画面信息密度"——
> 靠数字/对比/元数据让画面比口播信息密。此时数字无出处可标——凡拿不准的数字
> 挂 `<Figure>` 待补或回用户要出处，**别编**。

### Step 列表：每步 1 行

```
- step N (~Ts) — <屏幕内容>
```

| 规则 | 原因 |
|---|---|
| `step N` 1-indexed | 实现时 `step === N - 1`（零基偏移） |
| **`(~Ts)` 必填** | 按口播段字数 ÷ 4 估算。范围 3~45s（45s 是硬顶；**15s 是门禁 #19 的节奏警告线**——推荐把多数步控在 15s 内，长步留给"一个数+解读"的完整数据点） |
| **屏幕内容** | 一句话讲清这一步舞台上有什么（hero 数字/对比/表格行/风险点）。≤1 行，再多就该拆 step |
| 不写动画 / 不写实现手段 | 留给 Phase 4 |

### 口播节选（每章末尾，可选但推荐）

1~3 句节选，仅供对照"这章在讲什么"。完整文本回 `script.md`。音频合成回
`script.md` 切分完整文本，**不用** outline 节选。

## 命名规则速查

| 对象 | 规则 | 示例 |
|---|---|---|
| 章节 id | 小写 + 连字符 | `coldopen` |
| 章节文件夹 | `0N-<id>` | `src/chapters/01-coldopen/` |
| 章节组件 | `Chapter` 组件（`<folder>/index.tsx` 内） | `Coldopen` |
| CSS 类前缀 | **`.cdp-`**（门禁强制） | `.cdp-coldopen-*` |
| 音频文件 | `<step>.mp3`（**0-indexed**，与 narrations 下标一致） | `public/audio/01-coldopen/0.mp3` |
| narrations | 与组件同文件导出（机器生成，**章节 agent 不得手改**） | `export const coldopenNarrations = [...]` |

## 章节切分的经验法则

- **每章 3~8 步**。少于 3 太薄；多于 8 观众会忘记这章在讲啥
- **总时长 ÷ 30 秒 ≈ 章节数**（一章 30~60 秒讲完）
- **每章 = 一个聚焦主题**。"营收怎么样"与"为什么增收不增利"是两章
- **章节边界 = 口播稿里讲者换主题/换语气的位置**
- **财报节奏**：每个 step 一个数据点；一个数据点配一个"感受锚点"再配一个"解读"
  的话，就该拆成两步——别把三个动作挤进一步

## 自检（写完 outline **强制**执行，不可跳过）

> ⚠️ **硬性流程**：写完后必须自检 → 修改 → 再进 Checkpoint 1。执行方式（按能力
> 降级）：独立 reviewer agent（传 `outline.md` + 本清单 + `script.md`/`article.md`
> 路径，逐项核查+出结论）→ subagent → 自己严格逐项。拿到结论先按 fail 项改，再进
> Checkpoint 1。

- [ ] 每个 step 都是单一句屏幕内容描述，无"动画"行/"手段"行
- [ ] 无任何 step 写了具体毫秒/秒数（除 `(~Ts)` 口播估时）
- [ ] 每章信息池 ≥3 条，**每条带来源标注**（`—— 来源 年报第 X 页`）——没标注
      chapter agent 回不到原文
- [ ] **所有 step `(~Ts)` 累加 ≈ 顶部总时长**（误差 <10%）
- [ ] 章节切分符合"每章 3~8 步 / 30~60s 一聚焦主题"
- [ ] 素材清单分章节列出，✓/⚠️ 标注清楚
- [ ] 每个数据点都能回原文定位；无编造数字

写完看一眼：**outline 是不是干净到 chapter agent 能立刻开工 + 还有设计空间**？
是 = 合格。
