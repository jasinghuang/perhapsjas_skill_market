# 小红书档案（3:4）

> 平台档案 = 第一公民抽象：**画幅 / 安全框 / 渲染参数 / 语气基调**。语气**不随平台变**
> （财报解读的语气基线唯一，见 SCRIPT-STYLE 开头），本档案只管画幅与发布规格。

## 舞台与安全框

| 项 | 值 | 出处 |
|---|---|---|
| 舞台尺寸 | 1080 × 1440 | scaffold `--stage 3:4` |
| 安全框 | **按 16:9 基准比例折算**（`deriveSafeArea` 单一源） | 折算逻辑在 `templates/src/engine/safe-area.ts`；**3:4 的绝对值为比例折算，非用户视觉裁定**——档案定稿时需用户确认（KNOWN-ISSUES K-30），届时若调整需一并复核示例章节布局 |
| 档案级停留垫 | 不覆盖（走引擎默认 400ms） | 停留垫三级：引擎 400 → 档案 → `timing.json` 逐帧 |

## 发布规格

- 成片 `render/<slug>.mp4`：1080×1440 @30fps，h264 + aac
- 字幕：默认烧录；SRT 副产物同源
- 目标平台：小红书（竖屏 3:4，**常驻 UI 会遮挡边缘**——3:4 的安全框绝对值定稿前，构图从严，
  重要元素别贴边缘；定稿后按 K-30 更新）
