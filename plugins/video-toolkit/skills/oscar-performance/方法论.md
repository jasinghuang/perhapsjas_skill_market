# oscar-performance 方法论

版本 1.6。面向人的说明；Agent 执行入口是 [SKILL.md](SKILL.md)。

## 1. 这套方法论解决什么

AI 演员常见的问题不是“不会做表情”，而是：

- 只有情绪标签，没有触发和过程；
- 只有表情编排，没有人物对对手做的事；
- 只有台词轮流，没有话权、抢话、停顿和语言失败；
- 表演和空间、镜头、光影、声音脱节；
- 提示词是一堆形容词，不是可执行、可检查的规则。

`oscar-performance` 把这些问题拆成一条可执行的流水线：**理解 → 表演设计 → 场景耦合 → 提示词编译 → 自检**。每个阶段都有输入、输出和检查门。

## 2. 底层判断

### 2.1 先理解，再设计；先空间，再镜头；先因果，再风格

不先理解整场戏，写出来的表演只是“漂亮的局部”。不先锁空间，镜头和表演会互相打架。风格词永远放最后，它不能替代空间、时间、因果和连续性。

### 2.2 角色不演情绪，角色演任务/方向

角色不是“演悲伤”，而是对人或环境做一件事：让对方听完、确认信息、保护对方、完成手头工作。情绪是行动中被观众读到的东西，不是脸上的独立动作；不要求每场都有压抑或关系冲突。

这条原则直接来自 acting task：**任务是活的，表情是任务的证据。** 没有任务的表情，就是 playing the result。

### 2.3 先任务，后证据，再 AU

顺序不能反：

1. **任务层**：他此刻在对人或环境做什么？
2. **过程与证据层**：他如何处理刺激、维持或调整行动？在脸、声音、呼吸或身体上有什么可读证据？
3. **校准层**：需要时再加 AU + 强度，不堆编码。

唐国强篇的肌肉链、AU、量化，是对白暗流篇“语言失败”、acting-skill“眼睛的工作”的共同落地方式；它们不是独立的情绪公式。

### 2.4 事件先有起源，再有可见因果

事件不是孤立的“意外”或“因为”，而是人物目的、注意力、信息差、环境、路径交叉的结果。先回答：每个人此刻在追求什么？注意力在什么上？因此没在看什么？信息差是什么？环境/路径为什么让两人的行动在这一刻交叉？触发点是什么？第一次意识是什么时候？反应如何被各自的目的塑造？后果是什么？然后再用镜头、视线、遮挡、身体、声音让观众看见这条链。只写“意外”，观众看到的是“故意”。

## 3. 五阶段流水线

### 阶段 0：全局理解

- 读全稿，判断模式（创作/修订/诊断）。
- 填《场景理解卡》：任务约束、故事与人物、导演与视听、表演、执行与风险。
- 先看结尾，再命名这场戏的事件。
- 分开**场景共同方向**（全场共享、通常不说出口）与**人物个人目标**（每个人自己的战斗）。
- **场景引擎五问（必查）**：Goal / Obstacle / Tactic / Reversal / Value Shift。
- 标记假设与缺口：明写 / 强推断 / 决定性未知。

### 阶段 1：表演设计

- **Acting task**：场景共同方向 → 动机 → 个人目标 → 障碍 → 战术 → 逐拍动作。
- **处理过程**：起始任务与状态 → 感知/触发 → 处理与行动选择 → 可见/可听证据 → 结束与承接；即时反射不强插思考，持续状态不强造变化。每拍选 1–2 个主要证据，保留必要的发生过程。细则见 [02-performance](references/02-performance.md) §2.8。
- **人物丰满度**：私人动机、不能说出口的东西、矛盾/疤痕、生活痕迹；不新增设定，只加 1–2 个可见细节。
- **物件事件**：事件前/中/后/新状态；表情三股力（评估/社会管理/关系目标）；肢体链；连续性。
- **八维**：时间段、人物目的、情绪变化、台词触发词、面部动作与 AU、目光和身体、声音呼吸与停顿、结束状态和静止反应。
- **情绪弧线**：保护层（愤怒/礼貌/否认/照顾/控制等）→ 加压 → 裂缝（重申→泄露→代价）→ 失效 → 新状态。
- **台词与话权**：话轮、抢话/沉默、重叠、语言受阻四类、语言恢复。
- **微表情**：自然语言先行；肌肉链、不对称、矛盾共存、克制/中断、必要量化。
- **身体与小动作**：有心理依据的肢体细节、道具互动、支撑/重心/接触/结束落点。
- **无台词**：听、想、呼吸、目光、错峰反应、动作密度。

### 阶段 2：场景耦合

- 空间与轴线：双人/多人/一镜到底三套写法；世界坐标与画面坐标。
- 摄影机：物理路线、事件触发、摄影师误判、惯性；不用数字变焦。
- 焦点与景别：谁清晰、谁柔焦、焦点何时转移；景别分配细节。
- 构图：前景/中景/后景/最远层；主体位置 + 空间边界 + 留白方向 + 情绪作用。
- 光影：光源动机、方向、色温、光比、随人物移动的变化；反打不重打光。
- 声音：环境底噪、混响、画外声、对白空间、重叠、静默；声音有空间景别。
- 时间轴：按秒/段写景别、焦距、动作、对白、音量、转场。
- 连续性：身份、服装、道具、光向、轴线、视线、姿势、状态继承。

### 阶段 3：提示词编译

四层主干：

1. **全局控制**：搭片场，保证演员别变。
2. **人物内核**：声线、潜台词、情绪方向、真正想完成的目标。
3. **时间轴**：逐秒/逐段写说话人、原句、触发词、动作、重叠、听者反应、呼吸/停顿、禁止提前反应。
4. **声音与镜头**：口型、方位、环境声、切镜连续、机位/焦点/光影要点、明确禁止项。

技术参数与负面约束放附录/末段。关键表演过程必须进入最终复制正文；心理分析、检查结论不能代替指令。对白字段按适用范围填写；旁白与画内角色分别设计。

### 阶段 4：自检

- 可执行、有因果、有连续。
- 逐节拍四问：感知了什么？如何处理并改变或维持行动？观众从哪里读到？下一段接住什么？
- 最终复制块独立验收：分析充分不抵消正文缺项；动作物理成立与表演充分性分别判断；证据符合景别、时长与声画归属。详见 [05-verification](references/05-verification.md) §2.1。
- 文字复核三链：话权与声音交叠；语言受阻与口型/呼吸兼容；镜头/段落切换后的状态继承。
- 风险表：身份漂移、偏色、光源黏脸、跨轴、瞬移、服装/道具漂移、滑行/肢体融合、失重道具、塑料表演、表演过满、台词超时。
- 一次只改一层。

## 4. 八维表演检查

| 编号 | 维度 | 必须确认 |
|---|---|---|
| 1 | 时间段 | 这一拍在哪个镜头/时间窗；起止与时长预算；表演是否装得下 |
| 2 | 人物目的 | 向谁争取什么、为什么此刻行动、动作动词；起始如何维持自己 |
| 3 | 情绪变化 | 从何处到何处；启动、增强、受阻、消退；禁止哪些情绪提前出现 |
| 4 | 台词触发词 | 哪句、哪个词触发；同词多次出现要定位；触发后语言是恢复还是失败 |
| 5 | 面部动作与 AU | 可见部位、方向、速度、强度、阶段（onset/apex/offset）；AU 只作可选校准 |
| 6 | 目光和身体 | 注视对象与用途；姿态、手势、支撑、重心、接触、结束落点 |
| 7 | 声音呼吸与停顿 | 原词、声线、态度、重音、语速、口型、呼吸、停顿、重叠、语言受阻 |
| 8 | 结束状态和静止反应 | 留下什么供下段接续；情绪/身体余波；静止时的反应 |

横向检查：话权/话轮、连续性、禁止提前反应。

按角色/节拍引用最终正文证据，判定为已落实、沿用明确原文、偏弱、缺失、不适用或信息不足。关键适用项偏弱/缺失时先修正文，不能因表格填满、出现“自然呼吸”或全局写了“克制”就宣布通过；持续状态与不在画面的通道按具体理由判断。

### 4.1 人物丰满度

不是加设定，是加可见的矛盾、代价和习惯。先挖文本里已有的：规定情境、立场/价值错位、私人动机、个人目标/障碍、矛盾/疤痕、潜台词、权力关系、结尾双关。再放大：不对称/情绪错位、克制/中断、语言失败类型、语言恢复、小动作/道具/生活痕迹、听者任务、value shift。

公式：**私人动机 + 不能说出口的东西 + 一个可见的矛盾 + 一个具体习惯/物件 + 一次面具滑落 + 观众判断的变化**。每场挑 2–3 样，绑在触发点上。不新增剧情/身世/关系。

### 4.2 人物—物件交互

物件是给定情境的变化，也是关系的测量器。先理解它属于谁、什么历史、在戏里是障碍/替身/记忆/身份/工具。再写事件前（手在哪/注意力在哪）→ 事件中（意图/接触/力/声音/第一眼）→ 事件后（评估/社会管理/关系目标）→ 新状态（污渍/碎片/湿袖口/移位）→ 连续性。

表情不是预设“惊讶/尴尬”，是三股力：评估 + 社会管理 + 关系目标。第一眼看哪里暴露优先级。物件事件可以是反转、value shift、下一拍的触发；也可以只是生活质感。

## 5. 场景引擎五问（必查）

| 元素 | 它问什么 | 关键规则 |
|---|---|---|
| Goal | 主角不变的目标是什么？这场戏是不是通向它的因果链？ | 删掉这场戏链条还成立 → 这场戏失败；可以错在战术，不能错在目标 |
| Obstacle | 什么在威胁目标？威胁的是哪一步/整体？ | 是“威胁”不是“代价”；说不出风险就是假障碍 |
| Tactic | 障碍逼出了什么动作？ | 不完全信息下的合理猜测；失败必须带回新信息 |
| Reversal | 哪里反着来？ | 自己的动作反噬 / 隐藏 agency / 局势反转；一个 sequence 至少一次 |
| Value Shift | 观众对他的判断怎么变？ | 反转必须改变 before-verdict → after-verdict，否则无效 |

必查不等于必须“有”：单条 30 秒也要跑，每项可只写一行；不适用或未出现要写理由，不能跳过，也不能硬造反转。

## 6. 来源与取舍

- **唐国强篇**：八维、三层结构、情绪节拍、台词即表情时间轴、AU、正反案例。
- **对白暗流篇**：话轮、重叠、抢话、语言受阻、悲伤三股力、四层结构。
- **9 节整理稿 / 原始 S01–S15**：场景构建、空间、镜头、光影、声音、案例。
- **higgsfield-acting-skill**：acting task、scene goal、ending names the event、all in one event、physical channel。
- **higgsfield-prompt-engine**：五元素场景引擎、AUDIT、weakest point + minimal/clean fix。

合并原则：方法不删，重复表述合并；案例可去重，方法不可丢。逐条落点见 [source-map](references/source-map.md)。

## 7. 三种工作模式

- **创作**：从剧本/故事/分镜写完整提示词。
- **修订**：保留原结构、台词、镜头、风格；只改表演描述、与表演直接耦合的冲突、用户点名部分。
- **诊断（AUDIT）**：不重写，先跑场景引擎 + 八维，指出最弱一环，给最小修复和干净修复。

## 8. 边界

- 不调用视频生成、不索要媒体、不把文字设计说成成片效果。
- 不虚构剧情、人物关系、前史、台词。
- 不把作者叙述、教学案例写成本项目实测。
- 不承诺模型必然执行；AU 不是模型接口；数值不是逐帧保证。
