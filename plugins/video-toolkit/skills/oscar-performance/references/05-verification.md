# 自检与迭代：可执行、有因果、有连续

## 1. 三原则

### 1.1 可执行

每条指令都能被看到/听到/在文字里核对。

- “她很伤心”不可执行；“眉心聚拢、下唇颤抖、眼泪锁在眼睑边缘”可执行。
- “镜头很有电影感”不可执行；“摄影机从右前方后撤到右后方，因人物超过机位而转身”可执行。
- “光线很美”不可执行；“路灯从侧前上方照亮湿发，便利店溢光托住阴影”可执行。

### 1.2 有因果

每个变化有触发；每个镜头运动有理由；每个光变化有光源。因果不是一句“因为”或“意外”；因果链要能回答：人物目的 → 注意力 → 信息差 → 环境/路径 → 触发 → 第一次意识 → 反应 → 后果。镜头、视线、遮挡、身体要让观众看见这条链。

- 情绪变化：哪句台词、哪个词、哪个事件触发的？
- 镜头运动：因为人物起身、危险出现、声音传来，还是因为摄影师要看清？
- 光变化：因为人物走入屋檐、伞遮住顶光、点火成功？
- 话权变化：因为被触发抢入、因为退让、因为沉默？
- 事件：事件前每个人的目的是什么？注意力在什么上？信息差/环境/路径/触发点/第一次意识/反应/后果是什么？

### 1.3 有连续

身份、空间、光影、道具、情绪状态跨镜不重置。

- 切镜后，湿润程度、视线、呼吸、姿势不能重置。
- 人物前倾后，下一镜延续姿势。
- 对白停下，呼吸、衣料声、环境声继续。
- 一次善意或语言恢复，不自动消除冷、痛、疲劳、悲伤。

## 2. 逐节拍四问

每个节拍问：

1. **此刻感知了什么？** 他听见/看见/感觉到什么？
2. **如何处理？** 这项信息怎样使他维持或改变行动？即时反射不强加思考，持续状态不强加转折。
3. **观众从哪里读到？** 哪个证据及其发生过程让观众知道？只写心理解释或通用小动作不够。
4. **下一段接住什么？** 哪项反馈使下一动作成立，留下什么姿势、注意、情绪或未完成反应？

如果四问答不上来，先判断缺的是表演设计还是执行描述；依 [02-performance](02-performance.md) §2.8 修复，不靠增加表情或 AU 数量补齐。

### 2.1 最终提示词独立验收

先把理解卡、导演阐述、节拍表和检查结论放在一边，只读取实际交给生成工具的完整复制块。局部修订仅检查替换段及未改原文中的必要约束、前后接口，不扩大重写范围。

1. **过程可还原**：逐个关键节拍，从正文定位人物任务、感知/触发、处理与行动选择、可读证据、结束与承接。允许同一句承担多项；不要求固定字段或每拍转折。若“为什么换做法/为何继续”只能从分析表得知，编译未通过。
2. **表演与物理分别成立**：暂略画质、器材和物理连续性条款，仍能读到人物如何经历事件或维持任务。只有“转头、抬手、承重、迈步”且没有任务处理证据，表演偏弱；动作若已表现判断、抵抗、回应或维持，则不必另加表情。
3. **证据能被呈现**：证据符合已定景别、遮挡、声场和时间窗口，重要反应在切镜前发生或由下一镜可读的通道承接。背面/远景不能靠看不见的眼睑通过；局部锁定镜头时先改用可呈现证据，确有冲突再披露。
4. **归属正确**：现场说话者、画内听者、画外叙述者分别核对。旁白气口不能证明画内人物呼吸已设计，未听到的旁白不能触发角色反应；不用“无对白”将目光、身体、状态承接一并判不适用。
5. **正向过程足够且不越界**：禁止项不能代替人物实际怎么演；“克制/自然/每拍1–2个细节”不能替代发生过程。也不为通过检查新增冲突、动机、情绪高潮、固定延迟或装饰性呼吸。压缩或局部改写后，重查受影响的节拍与接口。

关键适用项偏弱或缺失时，先修正文，再复核并更新结论；缺乏信息或锁定约束使其无法成立时，明确披露缺口/冲突，不宣布整稿通过。独立验收是文字检查，不证明模型执行或成片质量。

## 3. 八维检查记录

按角色、节拍逐维核对。记录可简写，但每个适用维度都要有最终正文的具体句段；全段总结不能充当逐拍证据。判定为：

- **已落实**：正文过程充分，符合任务、呈现条件及前后状态。
- **沿用明确原文**：指出保留的原文依据；只用于原稿确已满足的部分，仍参加过程与呈现检查。
- **偏弱**：提到了该项，但过程、触发、归属或可读证据不足。
- **缺失**：适用但正文没有相关指令。
- **不适用**：说明该角色/节拍/维度的具体原因；不能按无对白或静止笼统豁免全部表演。
- **信息不足**：缺乏决定性输入；指出缺口，不把已知的薄弱描述改称未知。

| 角色/节拍 | 维度 | 判定 | 最终正文依据或缺口 |
|---|---|---|---|
|  | 时间段 |  |  |
|  | 人物目的 |  |  |
|  | 情绪变化 |  |  |
|  | 台词触发词 |  |  |
|  | 面部动作与 AU |  |  |
|  | 目光和身体 |  |  |
|  | 声音呼吸与停顿 |  |  |
|  | 结束状态和静止反应 |  |  |

不能只写“已查、自然、同上”，也不能以一个通用细节证明全段充分。缺项补到过程成立为止，原文已充分则保留；“自然呼吸”可以作为基线，但不能冒充需要专门设计的反应。无需每拍动用全部表演通道，AU 始终可选。

横向检查：人物丰满度（只挖文本/每拍 1–2 个细节）、物件交互（事件前/中/后/新状态/连续性）。见 [08-character](08-character.md)。

## 4. 场景引擎必查

每个输入都检查五问，并写判断：

| 元素 | 判断 | 依据/理由 |
|---|---|---|
| Goal | 成立 / 弱 / 不适用 |  |
| Obstacle | 成立 / 弱 / 假障碍 |  |
| Tactic | 成立 / 弱 / 不适用 |  |
| Reversal | 有（形式+位置）/ 无+理由 / 弱 |  |
| Value Shift | 有（before → after）/ 弱 / 不适用 |  |

如果障碍是假的、战术不是被逼出来的、反转无效，先披露结构问题；可以继续写表演，但不能用微表情补结构，也不能虚构反转。

## 5. 文字复核三链

### 5.1 话权与声音交叠

- 谁先说、谁抢入、重叠多久、谁覆盖谁。
- 抢入前，对方的尾音/口型是否还在？
- 抢入者是否先保持较低音量，再接管？
- 是否有人突然静音？除非有明确原因，否则不允许。

### 5.2 语言受阻与口型/呼吸兼容

- 口吃、哽咽、停顿，是否同时发生在呼吸和口型上？
- 不能同时指令“深吸气”和“连续清晰说话”。
- 不能同时指令“锁嘴”和“长句清晰”。
- 口吃是否落在最难面对的词，而不是平均分布？

### 5.3 镜头/段落切换后的状态继承

- 姿势、持物、湿润程度、未完成反应是否延续？
- 切镜后，情绪是否接住，还是重置？
- 画外声与画内口型是否归属清楚？
- 插镜是否留出了画外动作时间，又没有让手/道具瞬移？

## 6. 生成风险表

| 风险 | 文字层检查 | 提示词修复 |
|---|---|---|
| 身份漂移 | 参考图绑定是否写死五官/服装 | 加“严格遵循参考图”；禁止换脸 |
| 偏色 | 色彩脚本是否写面积/位置/明暗 | 固定主色/辅色/肤色/暗部 |
| 光源黏脸 | 光源是否有动机、方向、变化 | 写光源位置与人物移动的光比变化 |
| 跨轴/换边 | 轴线与站位是否唯一 | 写死左右/前后/摄影机活动区域 |
| 瞬移/数字变焦 | 机位变化是否写“怎么走过去” | 写物理路线；禁数字变焦 |
| 服装/道具漂移 | 连续性锁定项是否列全 | 写数量/材质/状态/继承 |
| 滑行/肢体融合 | 动作是否有支撑/重心/接触 | 写脚底接触、承重、惯性 |
| 失重道具 | 道具是否有重量/惯性 | 写持物、承重、释放 |
| 塑料表演 | 是否只有情绪标签、动作顺序或通用小动作 | 补任务处理过程与可读证据，按情境使用受阻、留白或不对称 |
| 表演过满 | 是否每镜都塞变化 | 控制动作密度；留“什么都没发生”的片刻 |
| 台词超时 | 字数/停顿/重叠是否算过 | 删冗余、留呼吸、标注重叠 |
| 情绪跳变 | 是否有过渡证据 | 加保护层裂开、声音破裂 |
| 物件瞬移/重置 | 物件状态跨镜不延续 | 写事件前/中/后、新状态、负面约束 |
| 物件失重/穿模 | 杯子像纸片/手穿杯 | 写接触点、力、重量、支撑 |
| 物件事件无反应 | 杯子掉了，人物继续念台词 | 写第一眼、评估、社会管理、修复 |
| 预知反应 | 物件还没掉，人物先惊 | 事件先发生，人物后反应 |

## 7. AUDIT 诊断输出

用户给已有脚本/提示词，问“哪里不对/为什么假/怎么改”时，按这个格式：

```text
场景/提示词：<一句话>

场景引擎
• Goal — <判断 + 一句依据>
• Obstacle — <判断 + 风险/尺度>
• Tactic — <是否被逼出来 + 失败带回什么>
• Reversal — <形式 + 位置；或 无+理由>
• Value Shift — <before → after；或 弱/不适用>

八维检查
• <落实/弱/缺失，逐项或只列关键项>

最弱一环：<只选一个；修它收益最大>

最小修复：<只改这一环，保留用户版本>
干净修复：<完整成立，可偏离原稿>
可选：<只在确实增加价值时给>
```

规则：

- 不重写全文；不改变锁定项。
- “最弱一环”按“修它收益最大”排序，不按问题数量。
- 最小修复只改一个点，其他保持用户版本。
- 干净修复可以偏离原稿，但要说明代价。
- 用户要成稿时转修订模式。
- 如果人物扁平或物件事件缺失，也列入八维检查：人物丰满度看“想要/怕/不能说”和 1–2 个细节；物件交互看事件前/中/后、第一眼、新状态与连续性。

## 8. 迭代策略

- **一次只改一层**：先修因果，再修表演，再修镜头/光影，最后修语言。
- **不在旧矛盾后叠加新规则**：发现冲突先消除旧文。
- **用户反馈是文本证据**：不冒充已看片；缺少决定性信息时只问必要的文字问题。
- **不把“等待视频验证”作为交付条件**：文字层能验证的先验证。
- **不越改越大**：局部请求只改局部；全文修订才动全文。

## 9. 边界

- 本 skill 只做文字设计与文字复核，不调用视频生成、不索取媒体。
- 文字结论只针对当前稿件，不承诺模型输出。
- 不把作者叙述、教学案例写成本项目实测。
- AU 不是模型接口；数值不是逐帧保证；提示词不是成片。

## 10. 验收清单

```text
[ ] 场景引擎五问已逐项判断（成立/弱/不适用+理由）
[ ] 八维已按角色/节拍核对，适用项有最终正文依据，偏弱/缺失未冒充通过
[ ] 最终复制块独立验收通过，分析表未代替表演指令；局部修订只检查本段与接口
[ ] 关键节拍有处理过程与可呈现证据；动作物理成立和表演充分性分别判断
[ ] 画外叙述与画内角色的刺激、声音、呼吸归属清楚，无对白/持续状态未被笼统豁免
[ ] 锁定项未越界；可创作项在允许范围内
[ ] 每个变化有触发；没有情绪跳变
[ ] 因果可见：观众能看见“为什么”，不只是读到“意外/因为”；目的/注意力/信息差/环境/路径/触发/第一次意识/反应/后果写清
[ ] 每个镜头运动有理由；没有跨轴/瞬移/数字变焦
[ ] 每个光变化有光源；反打不重打光
[ ] 时间预算成立：台词、动作、镜头时长能同时成立
[ ] 连续性：身份/服装/道具/光向/视线/姿势/状态继承
[ ] 话权与声音交叠写全；语言受阻与口型/呼吸兼容
[ ] 禁止提前反应已写；正向过程未被禁止项或“克制/自然”代替，没有表演过满
[ ] 人物丰满度：只挖文本、每拍 1–2 个细节、没有新增设定
[ ] 物件事件：事件前/中/后/新状态/连续性写清；没有瞬移/失重/预知
[ ] 没有虚构剧情/关系/前史/台词
[ ] 没有把作者叙述写成本项目实测
[ ] 未解决冲突与假设已披露
```
