# 人物丰满度与人物—物件交互

## 0. 这一层解决什么

- 剧本/提示词里的人物已经有了，但读起来“功能性”“扁平”“只承担剧情”。
- 不新增剧情、身世、关系，只把文本里已经有的东西挖出来，用表演细节放大。
- 两个镜头：
  1. **人物丰满度**：私人动机、矛盾、潜台词、语言失败、生活痕迹、观众判断变化。
  2. **人物—物件交互**：碰倒杯子、拿到东西、放下东西时，表情和身体怎么变，物件状态怎么延续。
- 这两层是**横向检查**，不新增第九维；分别落在八维的 D2/D3/D4/D6/D7/D8 和 D6/D8 + `03-scene` 连续性里。

## 1. 人物丰满度

### 1.1 原则：丰满不是加设定，是加可见的矛盾、代价和习惯

- 不是给人物加一段前史，而是让观众看见他“想要什么、怕什么、不能说什么”。
- 不是加更多表情，而是让表情受到阻力。
- 不是让所有人都有秘密，而是让这个人物在**这一刻**有一个不能直说的东西。
- 一句话：**丰满 = 私人动机 + 不能说出口的东西 + 一个可见的矛盾 + 一个具体的习惯/物件 + 一次面具滑落 + 观众判断的变化。**
- 不是每场六样全上；挑 2–3 样，绑在触发点上。

### 1.2 先挖：文本里已经有的东西

不要先编。先问文本已经给了什么：

- **规定情境**：他是谁、在哪、什么关系、之前发生了什么。一个已经拿了黑心钱的人，不能演“道德无辜”；动机必须服从规定情境。
- **立场/价值错位**：双方各自的立场为什么都成立？冲突不是谁对谁错，而是价值错位。
- **私人动机 vs 场景共同方向**：全场朝一个方向走，但每个人有自己的燃料。同一个方向，不同的理由。
- **个人目标与障碍**：他这场戏自己争什么？什么压着他？目标要普通、具体、可演，不能是主题。
- **矛盾/反差**：每人一个加号和一个减号，相对对方反转；表面特质常常是反面的疤痕——“不在乎”可能是希望耗尽后的保护。导演要导的是历史，不是表面。
- **潜台词**：台词表面说什么，底下要什么；他不能让对方知道什么。
- **权力关系**：谁持有话语权、谁准备接话、谁抢入、谁退让；权力变化最能显人物。
- **结尾双关/事件**：最后一句/最后一个动作常常暴露人物和事件真正的关系。

### 1.3 再放大：表演细节

挖出来之后，才用细节“显影”：

- **矛盾** → 不对称、情绪错位：单侧嘴角的半弧苦笑、不到眼底；“强迫自己微笑，但眼神空洞，泛着泪光”；两种情绪同时存在或 0.5 秒内转换。
- **代价** → 克制/中断：话咽回去、泪锁在眼睑边缘、摇头到第 10 度停住。高级的悲伤不是加表情，是让表情受阻力。
- **不能面对的东西** → 语言失败类型：羞耻/内疚 → 启动失败/口吃；急于自证 → 重复/重音；突然听懂残酷的事 → 沉默；想隐藏意图 → 说到一半改口。口吃落在最难面对的词上，不平均分布。
- **他真正在乎什么** → 语言恢复：被触发词击中后失去完整语言，但转到“保护对方”时短暂恢复完整句子。恢复不等于痛苦消失。
- **过去/生活** → 小动作、道具、生活痕迹：揉眉心、捂住嘴鼻、旧羊毛开衫、细纹、眼下色差、婚戒、两杯状态不同的冰美式。
- **听的时候** → 听者任务：不说话时在呼吸、整理手套、调整重心、转移视线；多人看画外时错峰反应。
- **观众判断** → Value Shift：观众开场怎么看他、结尾怎么看他；这个判断在哪一拍改变。人物是在观众反复 re-judge 的过程中变丰满的。

### 1.4 丰满度检查表

1. 他此刻想要什么？为什么现在必须说/做？
2. 他不能让对方知道什么？他怕什么？
3. 他的立场为什么成立？对方的立场为什么也成立？
4. 他身上有什么矛盾/反差？表面特质下面是什么疤痕？
5. 他有什么习惯动作/物件/生活痕迹，能承载过去？
6. 他说话失败时，是哪种失败？落在哪个词？
7. 他不说话时在做什么？听者在处理什么？
8. 观众开场怎么看他，结尾怎么看他？这个判断在哪一拍改变？

### 1.5 边界

- 不新增剧情、身世、关系、前史；只放大文本里已经有的东西。
- 每拍最多加 1–2 个细节；每个细节必须服务一个“想要/怕/不能说”的东西。
- 细节要绑在触发点上；没有触发的细节是装饰。
- 如果文本不支持，标“推断”或问，不暗补。
- 不把“丰满”变成“加戏”：不抢主角的节拍，不改变原有台词和结局。

### 1.6 示例：“我没事”

原句：

> 他平静地说：“我没事。”

扁平写法是贴一个情绪标签。丰满写法不是加身世，而是加“矛盾 + 代价 + 习惯 + 关系动作”：

> 他先把手机屏幕按灭，才说“我没事”。说的时候喉咙动了一下，眼睛没有回到她脸上。说完，他把杯子往她那边推了推。

没有新增剧情，但人物立刻有了：

- 一个不想被看见的状态（按灭屏幕）。
- 一个压回去的生理反应（喉咙动）。
- 一个回避（眼睛不回来看她）。
- 一个关系动作（推杯子）。

观众会开始猜：他在瞒什么？他为什么还要照顾她？这就是丰满。

### 1.7 示例：“不在乎”= 希望耗尽

表面：他一直说“随便”“都行”“无所谓”。
导演不要演“冷漠”，要演“希望耗尽后的保护”：

- 说“随便”前，视线在对方脸上停半秒，再移开。
- 手在菜单上停住，指尖压了一下，再合上。
- 对方真的做了决定，他反而轻轻吐出一口气，肩膀落下来一点。
- 不解释，不补一句“我真的不在乎”；让观众自己读到“他曾经很在乎”。

这就是“导历史，不导表面”。

## 2. 人物—物件交互

### 2.1 原则：物件是给定情境的变化，也是关系的测量器

同一个杯子，在不同戏里可能是：

- **障碍**：挡在他和她之间，他推不开。
- **替身**：他不能碰她，只能碰她的杯子。
- **记忆**：她母亲的杯子，碰倒不是“洒水”，是“碰了她的过去”。
- **身份/工具**：打火机、伞、手机，拿法本身在演人物。

所以先问：它属于谁？之前什么状态？有什么历史？人物和它是什么关系？谁看见？它改变什么？

### 2.2 设计链：事件前 → 事件中 → 事件后 → 新状态

| 阶段 | 要写什么 |
|---|---|
| 事件前 | 他的手在哪、正在做什么、注意力在哪；物件之前什么状态 |
| 事件中 | 意图/意外；接触点、力、声音；物件怎么反应；他第一眼先看哪里 |
| 事件后 | 第一反应（生理/呼吸/冻结/后退）；社会管理（掩饰/修复/利用/道歉/责怪）；对方反应 |
| 新状态 | 物件位置/状态/损伤/液体/碎片；谁身上湿了；下一拍谁继承什么 |
| 禁止 | 物件瞬移/重置/复制/穿模/失重；人物在事件前先反应；切镜后污渍/碎片消失 |

### 2.3 表情：三股力

不要预设“惊讶/尴尬/愤怒”。表情是三股力碰撞的结果：

1. **评估**：他判断发生了什么？（是我干的吗？她看见了吗？坏了吗？严重吗？）
2. **社会管理**：他想让她怎么想？（我很抱歉 / 没事 / 都怪你 / 我不在乎）
3. **关系目标**：他想从她那里得到什么？（原谅我 / 别说了 / 看见我难受 / 离我远点）

**关键**：他第一眼看哪里，暴露他的优先级。先看人，说明他怕她；先看杯子，说明他怕损失；谁也不看，说明他在压自己。

### 2.4 肢体：跟着重量和关系走

- **冻结**：手停在半空，身体不动；这是“评估”阶段。
- **后退/前倾**：后退是怕事，前倾是修复/控制。
- **接触**：手指先碰还是手掌接；拿杯柄还是杯身；力多大；物件有没有重量。
- **支撑**：单手撑桌、膝盖顶地、重心移到一条腿；身体要有支撑。
- **收回**：伸出去又停住/收回；这是“想说又不敢”的身体版。
- **清理**：拿纸巾、擦桌、捡碎片；清理方式暴露性格（仔细/粗暴/逃避）。
- **残留**：手抖、呼吸浅、下颌紧、湿袖口；事件结束后身体还在反应。

### 2.5 物件事件作为结构事件

它不只是“加真实感”，还可以是：

- **反转**：他自己的手势碰倒杯子，动作反噬。
- **价值位移**：观众从“他不在乎”到“他其实很怕她难过”——不是通过台词，是通过他先看她、拿纸巾的手抖、把碎片藏到身后。
- **触发词**：杯子的碎裂声成为下一拍的触发，对话停住。

### 2.6 连续性

- 新状态必须延续：污渍、碎片、湿袖口、移位的物件、损坏的把手。
- 声音有残响：碎裂声、液体声、纸巾摩擦声。
- 对方有反应：她看污渍还是看他？她退后还是递纸巾？
- 下一拍继承：谁在清理、谁不说话、谁的手在抖。
- 插镜不能替代动作时间；画外动作不能让手/物件瞬移。

### 2.7 AI 风险与负面约束

- 物件瞬移、重置、复制。
- 物件失重：杯子像纸片。
- 手穿模/穿杯。
- 液体/碎片切镜后消失。
- 人物在物件掉落前先反应（预知）。
- 物件大小/材质变化。
- 声音与动作不匹配。

写进负面约束，只写当前风险，不堆长清单。

### 2.8 检查表

1. 这个物件是什么、属于谁、之前什么状态、有什么历史？
2. 人物和它是什么关系（道具/障碍/替身/记忆/身份）？
3. 事件前他的手在哪、注意力在哪？
4. 事件是意图还是意外？接触点、力、声音、物件怎么反应？
5. 他第一眼先看哪里？
6. 第一反应是什么（生理/呼吸/冻结/后退）？
7. 社会管理是什么（掩饰/修复/利用/道歉/责怪）？
8. 新状态是什么？下一拍谁继承什么？哪些不能重置？

### 2.9 示例：碰倒杯子

场景：夫妻隔桌争吵；杯子是她的，母亲留下的；他挥手时碰到杯子。

**事件前**：他的手在半空，正在比划；杯子靠近她的手；他看着她，不看杯子。

**事件中**：前臂碰到杯子；杯子倾倒；水洒在桌面；陶瓷碰木桌的声音；她的手往后缩。

**事件后（意外 + 想修复）**：

- 第一反应：手停在半空，眼睛睁大，吸气。
- 第一眼：先看她的脸，再看杯子，再回她。
- 社会管理：下颌收紧，嘴开又合；说“没事”说得太快。
- 修复：伸手拿纸巾，手抖；擦的时候不看她。
- 对方反应：她看着污渍，不看他。
- 新状态：污渍扩大；杯口缺了一角；她的袖口湿了；纸巾湿透；对话停住。
- 残留：他的呼吸变浅，下颌还紧；湿袖口贴着皮肤。

**事件后（故意 + 想施压）**：

- 没有惊；手停住，眼睛一直看她。
- 道歉来得很晚，或没有。
- 身体很稳；杯子只是工具。
- 对方反应：她后退，或者更安静。
- 新状态：污渍在两人之间，像一条界。

**结构用法**：这个事件可以是 reversal（他的动作反噬），也可以是 value shift 的落点（观众从他“ careless”到“他其实怕她难过”，或从“他失控”到“他在用这个动作逼她”）。表演的落点不在“杯子掉了”，而在“他先看谁、怎么修、修不修得好”。

## 3. 放回八维与流程

- **人物丰满度**是横向检查：主要落在 D2（目的）、D3（情绪变化）、D4（面部）、D6（台词/声音）、D7（话权）、D8（结束/连续）。
- **物件交互**主要落在 D6（目光和身体）、D8（结束/连续），以及 `03-scene` §9 连续性。
- 不新增第九维；节拍表可以加一列“物件事件”，只写与本拍有关的物件变化。
- 写进提示词的位置：
  - 人物内核：私人动机、不能说出口的东西、矛盾/疤痕。
  - 时间轴：事件前/中/后、第一眼、社会管理、新状态。
  - 声音与镜头：物件声音、接触点、重量、连续性、负面约束。
- 不要把所有人物都写成“有秘密”；只给**这场戏需要**的 2–3 个细节。
