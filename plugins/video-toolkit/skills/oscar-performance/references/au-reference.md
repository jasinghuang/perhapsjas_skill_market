# AU 参考：FACS 动作单元表（可选校准）

AU 来自 FACS（Facial Action Coding System，面部动作编码系统），由 Paul Ekman 与 Wallace Friesen 于 1978 年发布，2002 年大幅更新。它把表情拆成独立于情绪解释的动作单元，每个 AU 对应一块或一组面部肌肉的收缩或放松；也是影视 CG 面部动画 blendshape 的行业标准。

## 使用规则

1. **自然语言先行**：先写人话能看见的动作，再用 AU + 强度做辅助校准。
2. **AU 不是情绪公式**：AU 04 配咬牙前倾可能接近愤怒，配眉内侧抬起、目光下落则可能是痛苦；组合语境比编号重要。
3. **不要堆编码**：只选关键 AU；不要每个镜头都列一串。
4. **模型不一定稳定解析所有 AU**：AU 是给写作者的精度工具，不是模型接口。
5. **先看见，再命名**：把脸分成眉毛、眼睛、鼻翼、嘴唇、下巴，观察哪里在动、往哪个方向动、动作多强、被哪句台词触发；先用人话记录，再查 AU。

## 强度分级（A–E 后缀）

| 级别 | 含义 |
|---|---|
| A | 微弱可察（Trace） |
| B | 轻微（Slight） |
| C | 明显（Marked） |
| D | 强烈（Severe） |
| E | 极限（Maximum） |

例子：AU 1A 是最微弱的眉内侧上提；AU 1E 是该人可达的最大强度。

## 侧别修饰符

| 修饰符 | 含义 |
|---|---|
| R | 仅右侧 |
| L | 仅左侧 |
| U | 单侧（未指明哪边） |
| A | 双侧但不对称 |

## 情绪对应的 AU 组合（EMFACS，写作时对照）

| 情绪 | AU 组合 |
|---|---|
| 快乐 Happiness | 6+12 |
| 悲伤 Sadness | 1+4+15 |
| 惊讶 Surprise | 1+2+5B+26 |
| 恐惧 Fear | 1+2+4+5+7+20+26 |
| 愤怒 Anger | 4+5+7+23 |
| 厌恶 Disgust | 9+15+17 |
| 轻蔑 Contempt | R12A+R14A（单侧） |

注意：这些是常见组合，不是公式。真实表演里，情绪常常是混合的、受阻的、不对称的；先写可见动作和语境，再用组合做参照。

## FACS 版本说明

FACS 2002 版手册共 500 余页，另含动作描述符（AD）与大量组合规则；上表为提示词写作常用的主干部分。写提示词时，先用自然语言描述可见动作，再以“AU 编号 + 强度”做辅助校准，不要只堆编码。
