# 场景耦合：空间、摄影机、焦点、光影、声音、时间轴

表演不是孤立的脸。它发生在空间里，被摄影机选择，被光影塑造，被声音托住，被时间切分。这一层只写与表演、叙事直接耦合的部分；纯摄影参数放 [04-prompt](04-prompt.md) 的附录。

## 1. 总原则

- **先空间，再镜头。** 先锁轴线、站位、朝向，再设计摄影机路线。
- **镜头运动必须有理由。** 因为人物起身、因为危险出现、因为声音传来；不是“为了电影感”。
- **景别变化靠摄影机真实靠近/后退**，不靠数字变焦。
- **控制五件事**：空间、时间、因果、摄影机、连续性。风格词放最后。
- **摄影机是有身体、有脚步、有反应时间的人。**

## 2. 空间与轴线

### 2.1 双人

- 两人隔桌相对：只设一条表演轴，摄影机始终在同一侧。
- 固定左右：妻子在左、向右看；丈夫在右、向左看。
- 人物从坐姿变站姿，也不能交换方向。
- 所有推进、横移、后撤、上摇都留在轴线同一侧。
- 正反打用对方肩部/耳侧/头发占画面约一成作柔焦前景；下方放水杯、餐盘作第二层前景；不遮眼睛和嘴。

### 2.2 多人

- 先锁空间关系：谁面对谁、谁在谁前后、是否允许换位。
- 站位要具体：B 永远在 C 左边，C 永远在 B 右边；A 加入后形成浅三角；进入某区域 A 领先半步，B 跟在右后侧，C 继续在 B 右边；最终固定为“A 左、B 中、C 右”。
- 不是机械横排，而是带前后 5–15 厘米差异的自然浅弧。
- 整条视频中，人物朝向、左右关系、前后关系、摄影机活动区域保持一致；位置互换要规避。
- 多人构图分层：前景肩/手臂/栏杆；中景当前承担情绪的人；后景另一角色/群众；最远层城市/车流/灯光。

### 2.3 一镜到底

- 先建立一套可持续遵守的“一镜到底空间规则”：这不是多个漂亮镜头拼起来，而是一台真实摄影机在 30 秒内完成一次连续运动。
- 每次机位变化写“摄影师怎么走过去”：
  - 开场在人物右前方后撤；
  - 人物依次超过机位后，摄影师真实转身进入右后方跟拍；
  - 到车边仍留在车辆右侧，再向左回摇观察远处人物，随后向右回摇起步汽车；
  - 汽车加速后，不能徒步追车；同一摄影机交给移动平台上的手持摄影师，从车尾右后逐渐靠近后窗，最终同速进入后排。
- 方位约束写具体：C 的掩体固定在停车位后方 45–50 米，摄影机 9–15 秒只允许半米到一米的小幅横移，不能为了拍 C 突然推进几十米。
- 规则写得越具体，AI 越不容易越轴、换边、复制车辆。

### 2.4 世界坐标 vs 画面坐标

- 世界坐标：规定人物/车辆逃跑方向为“前”，来路为“后”；摄影机开场在右前方，转身后变为右后方，到车旁仍在右侧。
- 画面坐标：朝后看时，世界左侧会映射到画面右侧；因此较近的追击车必须出现在后窗画面的右边缘，远车保持中部。
- 两者都写，模型才知道“方向”不是随镜头旋转的。

### 2.5 越轴、换边、复制人物

- 越轴/换边是高风险项，写进负面约束。
- 位置互换、左右关系漂移、复制人物、穿模，都是多人 AI 视频的高频失败。
- 解决方式不是“提醒模型注意”，而是把站位、朝向、摄影机活动区域写成唯一解。

## 3. 摄影机

### 3.1 物理路线

- 写清摄影机从哪到哪：人物 1 左前方 → 正侧方 → 右后方 OTS。
- 明确运动轨迹、轴线约束、避免无意义绕拍。
- 镜头从人物 1 背后 → 左侧 → 左前方，不意味着摄影机穿进人物之间；而是在安全半弧内通过横移、后撤、改变构图。

### 3.2 事件触发

- 不是摄影机提前等事件，而是事件先发生，镜头后反应。
- 写“谁先动、镜头为什么跟”：
  - 人物超过机位，摄影机被迫转身；
  - 车边掩护时，镜头因远处的危险回摇；
  - 发动机升转之后，摄影机才被声音和动作拉回车辆；
  - 摄影机可以被声音“拽过去”。
- 这种“事件先发生，镜头后反应”能明显减少机械感。

### 3.3 摄影师误判与惯性

- 允许摄影机慢半拍、提前、减速、落后。
- 追上人物后，因惯性多走 10–15 厘米，再小幅回收。
- 走一步、后撤、重新构图，甚至轻微过冲，再及时修正。
- 手持感来自人体惯性，不是随机晃动。

### 3.4 景别变化

- 靠摄影机真实靠近/后退，不靠数字变焦。
- 景别变化要有叙事理由：靠近是因为要看清迟疑；后退是因为要保留距离。
- 远景读姿态、距离、路径；中景读手势、重心；近景读眼神、嘴唇、呼吸。

### 3.5 手持感

- 轻微、低频、不规则的呼吸漂移；不是随机抖动。
- 站定后仍保留更轻的手持浮动，避免“停稳”被理解为完全冻结。
- 摄影机持续照顾眼睛与留白，吸收步伐冲击。

## 4. 焦点与景别

### 4.1 焦点是叙事工具

- 不要让所有人永远同时清楚。
- 用焦点变化代替解释性对白。
- 写清：谁清晰、谁柔焦、背景还能看懂什么、焦点何时转移。
- 焦点可以短暂从追赶者脸上漂移，越过他们落到远处女人身上，再迅速拉回；模拟摄影师在高速运动中重新判断主体。

### 4.2 人工跟焦迟滞

- 允许 0.1–0.3 秒轻微迟滞，比 AI 自动贴眼更真实。
- 焦点优先锁说话者靠近摄影机的一只眼。
- 枪口出画时，眼神仍可作唯一锚点；焦点不轻易移开面部。

### 4.3 景别分配细节

- 近景：眼神、手指、嘴唇、呼吸。
- 中景：手势、重心、肩线、身体距离。
- 全景：肩线、站姿、人物之间的距离。
- 远景：姿态、路径、人与空间的关系。
- 大光圈近景要明确焦点落在眼睛还是火焰；远景保留空间结构。

## 5. 构图与分层

### 5.1 分层

- 前景：肩膀、手臂、栏杆、杯子、对方耳侧/头发。
- 中景：当前承担情绪的人。
- 后景：另一角色、群众。
- 最远层：城市、车流、灯光、建筑消失点。
- 例子：A 前景偏左、D 后景偏右，通过景深和焦点切换建立人物关系；B 近景时，让 C 只保留肩膀或头发作为虚化前景，形成“C 前景 → B 主体 → 城市背景”的三层结构。

### 5.2 构图公式

**主体位置 + 空间边界 + 留白方向 + 情绪作用。**

例子：“人物位于右侧三分线，左侧保留空旷湿街，前景是模糊路沿，远处灯光渐隐，突出孤独。”

位置变化由摄影机取景完成，人物脚下位置保持连续。

### 5.3 前景的边界

- 前景增强压迫感和空间纵深，但不能遮挡眼睛、嘴部和关键动作。
- 对方肩部/耳侧/头发占画面约一成作为柔焦前景；下方水杯、餐盘作第二层。
- 前景不是越多越好；只保留能建立关系和纵深的层。

## 6. 光影与色彩

### 6.1 光源动机

- 写清光从哪里来：路灯、便利店溢光、壁炉、餐灯、窗光、日光灯。
- 写方向、色温、光比：路灯从侧前上方照亮湿发与脸部；便利店溢光和湿地反光托住阴影。
- 光随动作变化：伞遮住顶部光，人物略微变暗；点火成功，暖光只短暂照亮手指与下颌。

### 6.2 光比与色温

- 例子：“柔和光质、高反差光比”：面部灰阶柔和，背景低约 1.5 档；暖色餐灯与冷灰蓝夜景形成克制对比；暗部仍保留皮肤、眼睛和衣物层次。
- 例子：冷蓝灰石墙、银灰盔甲、深绿花园、微暖肤色、深红披风形成稳定的综合色彩关系。
- 不是“画面够不够艳”，而是镜头从近景到远景后，整体调色是否还在同一个世界里。

### 6.3 动态光

- A 从较亮区域走入屋檐附近，脸部亮度自然下降。
- B/C 处于遮阴区域，顶部更暗、侧脸接受墙面反光。
- 跨越警戒线后，随着人物与建筑位置改变，脸部光比变化。
- 避免 AI 常见的“光源黏在人脸上”。

### 6.4 反打

- 反打后，光在画面中的方向改变，但实际光源位置不变。
- 例子：壁炉在画面左侧；反打后，暖光从画面右侧来，但壁炉仍在原来的空间位置。
- 每个镜头重新生成光源方向，是 AI 高频错误；写进负面约束。

### 6.5 色彩脚本

- 先确定主次，再指定颜色落在哪里。
- 例子：低饱和蓝灰雨夜，暗部保留墨绿与灰紫，人物嘴唇和鼻翼保留少量血色，背景点缀少量暗酒红。
- 色号可以辅助，更关键的是颜色的面积、位置和明暗关系。
- 肤色保持自然冷中性；不要让整体偏色。

## 7. 声音

### 7.1 声音有景别

- 镜头转向追赶者时，女主的呼吸声向声场远端移动，追赶者的脚步和喘息占据声音中心。
- 镜头重新找到女主，她的喘息再次成为主体。
- 声音的空间位置要跟着镜头和人物距离变化。

### 7.2 环境底噪、混响、画外声

- 环境底噪持续存在：室内日光灯镇流器、远处车流、雨声、火声。
- 混响建构空间尺度：空旷房间的电话回声、狭窄走廊的短混响。
- 画外声：谁在画外、声音从哪个方向来；声音可以先入画。

### 7.3 对白空间与重叠

- 对白有空间位置：说话人离摄影机多远，声音在声场的前/中/后。
- 抢话标注重叠与覆盖关系；谁先收住、谁接管主要声音。
- 对白停下，呼吸、衣料声、环境声继续。

### 7.4 静默

- 静默不是绝对无声；保留呼吸、环境底噪、远处车流。
- 结尾只留呼吸和远处车流，让情绪通过声场收紧，而不是持续喊叫。

### 7.5 声音建筑

- 用声音细节建构空间：日光灯镇流器声、电话铃声在空旷房间的回声、持续的手机电流噪音。
- 这些细节让观众相信空间的物理尺度（空旷、破败、潮湿）。

## 8. 时间轴

### 8.1 按秒/段写

每段同时写清：景别、焦距、动作、对白、音量、转场逻辑。

例子（30 秒文戏）：

- 0–2 秒：建立双人关系。
- 2–7 秒：丈夫抢话。
- 7–11 秒：妻子抛出事实。
- 随后：大近景、打断、声音先入画推动冲突。
- 最后：极慢推近、沉默收束。

### 8.2 对白预算

- 对白必须控制长度，预留呼吸、停顿与两次语言重叠。
- 不能让每秒都被台词填满。
- 台词、动作、镜头时长三者要能同时成立；冲突要披露。

### 8.3 动作密度

- 不是每秒一个动作；稀疏、克制的动作能放大张力。
- 让“什么都没有发生”的片刻成为情绪回响的空间。

### 8.4 时间窗与节拍

- 一个镜头可以含多个节拍；一个反应也可以跨镜持续。
- 不为分节拍增切镜，不强制等长分段。
- 子节拍不能越出所属镜头，却继续指令该镜头已经看不到的表情。

## 9. 连续性

### 9.1 锁定项

- 身份/五官/发型/服装/身高与参考图强绑定。
- 道具数量、材质、状态、历史痕迹写清；两杯冰美式，一杯没动、一杯融化。
- 物件事件的完整设计见 [08-character](08-character.md) §2：事件前/中/后、表情三股力、肢体链、新状态与连续性。
- 服装磨损、妆发细纹/瑕疵、婚戒/衣领/视线不跳位。
- 姿势、持物、湿润程度、未完成反应跨镜继承。
- 光向、轴线、视线、屏幕方向保持一致。
- 空间结构锁定：左侧始终为石像墙、右侧始终为花园、长廊只能向右弯曲。

### 9.2 插镜与画外时间

- 插镜可以留出画外动作时间：吸烟通过猫的插镜留出画外完成的时间，再接背影吐烟。
- 但插镜不能替代动作时间，不能借画外让手与道具瞬移。
- 画外声与画内动作要有归属：谁在画外说话，口型在谁身上。

### 9.3 状态继承

- 切镜后，湿润程度、视线、呼吸、姿势不能重置。
- 一次善意或语言恢复，不自动消除冷、痛、疲劳、悲伤。
- 人物前倾后，下一镜延续姿势；对白停下，呼吸与微弱火声继续。
- 物件的新状态（污渍/碎片/湿袖口/移位）跨镜继承；完整检查见 [08-character](08-character.md) §2.6。

## 10. 常见失败

| 失败 | 症状 | 修复 |
|---|---|---|
| 越轴/换边 | 正反打人物左右互换 | 写死轴线、站位、摄影机活动区域 |
| 瞬移 | 一镜到底机位跳变 | 写“摄影师怎么走过去” |
| 数字变焦 | 景别突然拉近但空间没变 | 改为摄影机真实靠近/后退 |
| 无意义绕拍 | 镜头绕人转但没有叙事理由 | 每个运动绑定事件/动作 |
| 光源黏脸 | 人物转头，光向重新生成 | 写光源位置、反打方向、动态光比 |
| 偏色 | 镜头拉远后整体变色 | 固定主色/辅色/肤色/暗部 |
| 前景遮眼 | 肩膀挡住眼睛/嘴 | 前景不遮关键动作 |
| 构图无留白 | 人物塞满画面 | 主体位置 + 空间边界 + 留白方向 |
| 声音无空间 | 所有人声一样近 | 写声音景别、距离、画外方向 |
| 台词超时 | 每秒都塞满台词 | 留呼吸、停顿、重叠 |
| 状态重置 | 切镜后眼泪/姿势/持物消失 | 写跨镜继承 |
| 穿模/复制人物 | 多人场景人物融合/复制 | 固定站位、朝向、前后关系 |

## 11. 事件起源与因果链

**事件不是孤立的“意外”或“因为”，而是人物目的、注意力、环境、信息差和路径交叉的结果。**

### 11.1 先理解起源

1. **事件是什么**：用一句可观察的话说清发生了什么。
2. **每个人物在事件前的目的**：他正在追求什么？为什么现在必须做？
3. **注意力分配**：他的注意力在什么上？因此没在看什么？
4. **信息差**：他知道什么、不知道什么？对方知道什么？
5. **环境条件**：什么空间/声音/遮挡/人群/时间压力促成了这件事？
6. **路径交叉**：两人的行动路线为什么在这一刻交叉？是偶然、计划、误会，还是外部事件？
7. **触发点**：因果链的最后一环是什么？
8. **第一次意识到**：谁先意识到？什么时候？是否已经太晚？
9. **反应**：每个人物的目的如何塑造他的反应？不是统一的“惊讶”。
10. **后果**：事件改变了什么？哪个目的重新接管？
11. **叙事功能**：这个事件是障碍、反转、催化剂、揭示，还是纯生活质感？

### 11.2 再设计可见证据

观众要能看见这条链，而不是只读到“意外”：

- **目的**：事件前每个人正在做什么、看什么。
- **注意力/信息差**：头低着、眼睛盯着某物、没扫视前方。
- **遮挡/环境**：箱子、椅子、柜子、转角、人群、噪声。
- **路径**：谁从哪进入主通道，谁一直沿通道走。
- **第一次看见**：抬眼/抬头太晚。
- **惊讶证据**：接触瞬间身体一僵、眼睛睁大、吸气、手抬起。
- **镜头揭示**：镜头让观众看见目的、注意力、遮挡和路径。
- **禁止预知**：事件前没有对视、没有提前缩肩、没有提前减速、没有“知道要发生”的身体。

### 11.3 模板

```text
事件起源卡
- 事件：
- A 事件前的目的：
```
