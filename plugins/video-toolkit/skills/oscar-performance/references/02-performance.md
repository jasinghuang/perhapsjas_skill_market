# 表演设计：任务、八维、微表情、台词与身体

## 1. 总原则

### 1.1 角色不演情绪，角色演任务/方向

角色不是“演悲伤”，而是“对人或环境做一件事”：让对方听完、确认信息、争取回应、保护对方、完成手头工作。情绪是行动中被观众读到的东西；不要求每场都有压抑、关系冲突或情绪高潮。

- 不要写“女人非常悲伤地说”，再贴一句台词。
- 要写：她此刻在对谁做什么？哪句话击中她？她的身体怎么反应？她怎么压回去？最后停在什么状态？

### 1.2 先任务，后证据，再 AU

顺序不能反：

1. **任务层**：他此刻在对人或环境做什么？
2. **过程与证据层**：他如何处理眼前信息、维持或调整行动？在脸、声音、呼吸或身体上有什么可读证据？
3. **校准层**：需要时再加 AU + 强度，不堆编码。

没有任务的表情，就是 playing the result；只有肌肉清单、没有任务的提示词，会让模型“摆脸”而不是“演戏”。

### 1.3 高级表演是受阻

一个人越痛苦，越努力表现得没事。两股力量同时在脸上，观众才相信。

公式：**生理泄露**（眼红、吞咽、气息失控）+ **自我控制**（移开视线、不落泪、压回哭腔）+ **关系目标**（快崩溃仍先保护对方）。

### 1.4 每拍只推进一个主要心理变化

不要眉毛、嘴角、双手、呼吸同时夸张。一个节拍选一个主要变化，其余保持；让观众跟得上。

“每拍 1–2 个细节”限制并行证据的数量；一个证据可以包含触发、发展、受阻或收束。克制不等于省略处理过程；静止也可以是在持续观察、等待回应或维持某种姿态，不必每拍都改变情绪。

## 2. Acting task：把目的变成动作

### 2.1 场景共同方向

一场戏有一个共享的、通常不说出口的方向，所有角色都在朝它走。先写这一句，再写每个人。

例子：母亲给儿子装箱、一小时后参军——共同方向是“让这次告别不痛，别让彼此带着难过走”。

它不是影片的主题/反转/揭示。角色不演主题；主题是观众从行动里读出来的副产品。

### 2.2 动机：不同的燃料，同一个方向

所有角色朝同一个方向走，但每个人有自己的理由：儿子为了让母亲安心，母亲出于迷信（出门前不掉泪）。同一个向量，不同的燃料——燃料让每个人的表演有区别，但整场戏仍然统一。

动机要服从规定情境：一个已经拿了黑心钱的人，不能演“道德无辜”。

### 2.3 个人目标

从动机长出来：这个人自己在戏里争什么？要普通、具体、可演。

- 不要写成场景共同方向的同义词。
- 不要写成主题。
- 例子：母亲“送他走稳，别让他带走我的怕”；儿子“让她安心，显得我已经准备好了”。

### 2.4 障碍

什么在压着这个方向？通常不是反派，而是“真实感受要浮出来”。一个裂缝，共同方向就塌。

观众感受到的压力，恰恰来自“没有人去演它”；所有人都在把它挡在外面。

### 2.5 战术：对对手做什么

战术是投入的、逐拍的追求，写成“他对对手做的动作”，不是外部表情：

- 检查对方两只眼睛里有没有一点信任。
- 每说完一点，确认有没有落地；对方是感兴趣，还是准备冷笑。
- 偷看，又在被发现前收回。
- 打量对方、记住对方，比较“我感觉到的”和“他表现出来的”。

有对白时，节拍要绑在具体台词上。剧本需要时，标出“燃料用尽、句子断掉”的位置——那个断裂就是这场戏的交付。

无对白或无人际对手时，战术落在环境与手头任务上：辨别、试探、核对、等待、继续。绑定已有的感官刺激或行动反馈，不硬套关系目标，也不为制造阻力新增事件。

### 2.6 眼神工作作为 action

眼睛不是“动一下”，而是在做任务：

- 说话时持续看对方两眼，找信任/找裂缝。
- 对方说完，眼睛先确认“他是认真的吗”，再决定接不接。
- 听的时候，眼睛在对方脸上“读”下一个动作，而不是空洞凝视。
- 被击中时，视线先躲开，再强迫自己看回去。

**安全线**：眼神始终在任务上，不能冻结、玻璃化、失焦；保留自然眨眼节奏（AI 模型需要这一句）。

### 2.7 逐拍写法与模板

```text
ACTING TASK — [人物]（他完全投入战术；工作发生在眼睛里）：
场景共同方向（共享、不说出口）：[一句]
动机（他的燃料）：[为什么是他推这个方向]
个人目标：[他自己的战斗]
障碍：[什么压着方向；一个裂缝的代价]
战术：[他对对手做什么；眼睛的工作作为 action]
逐拍：
— “[台词]” — [对对手的动词 + 眼睛在检查什么]
— “[台词]” — [动词 + 眼睛的工作]
— [句子在哪里断掉]
（安全线：眼神始终在任务上，不冻结、不玻璃化；自然眨眼。）
```

### 2.8 从感知到行动的表演过程

先找人物任务发生推进、受阻、维持或调整的关键节拍，不按每次转头、迈步机械分拍。逐拍建立：

```text
起始任务与状态 → 感知/触发 → 如何处理、为何维持或改变行动 → 可见/可听证据 → 结束状态与下拍承接
```

- **处理**：他在辨别、比较、误解、接受、抵抗，还是继续原有工作？说明信息如何作用于行动；不只写“看见后做下一步”。即时反射可以由刺激直接引发，不强插思考或迟疑。
- **证据**：为这个过程选 1–2 个主要通道，如目光如何搜索/确认、动作如何延续/中止、声线如何维持/改变。说明关键证据的发生顺序和必要的收束；不只列“眨眼、松肩、自然呼吸”。证据必须符合人物、风格和景别。
- **衔接**：写明哪项信息或反馈足以使下一动作发生；尚未得到结果时，人物怎样继续等待、控制或执行。持续状态允许结束时不变，但要读得出他在维持什么。
- **边界**：心理过程只能取自文本与允许的表演设计；需要新增动机时标推断或披露缺口。不要普遍添加压抑、害怕、面具滑落、深呼吸或固定延迟。

动作准确解决“身体怎样做”，表演设计还要让观众读到“这个人此刻怎样经历这件事”；同一个动作可以同时完成两者。无需在成稿中保留这些字段名，把必要过程写成连贯指令。

## 3. 八维检查

| 编号 | 维度 | 必须确认 |
|---|---|---|
| 1 | 时间段 | 这一拍在哪个镜头/时间窗；起止与时长预算；表演是否装得下 |
| 2 | 人物目的 | 向谁争取什么、为什么此刻行动、动作动词；起始如何维持自己 |
| 3 | 情绪变化 | 从何处到何处；启动、增强、受阻、消退；禁止哪些情绪提前出现 |
| 4 | 台词触发词 | 哪句、哪个词触发；同词多次出现要定位；触发后语言是恢复还是失败 |
| 5 | 面部动作与 AU | 可见部位、方向、速度、强度、阶段（onset/apex/offset）；AU 只作可选校准 |
| 6 | 目光和身体 | 注视对象与用途；姿态、手势、支撑、重心、接触、结束落点 |
| 7 | 声音呼吸与停顿 | 原词、声线、态度、重音、语速、口型、呼吸、停顿、重叠、语言受阻 |
| 8 | 结束状态和静止反应 | 留下什么供下段接续；情绪/身体余波；静止时的反应 |

逐角色、逐节拍核对，判定与证据要求统一见 [05-verification](05-verification.md) §3。全段概括不能代替逐拍依据，动作连续性成立也不代表表演过程充分。

**横向检查（不在八维内，但必须做）：**

- **话权/话轮**：谁持有话语权、谁准备接话、谁抢入、谁退让；并入第 4、7 维。
- **连续性**：身份、服装、道具、光向、轴线、视线、姿势、状态继承；单独成表。
- **禁止提前反应**：每个节拍必填，检查第 3、4 维。

## 4. 情绪节拍与情绪弧线

### 4.1 时间窗

按秒/段拆，每段写：

```text
起始任务与状态 → 感知/触发 → 处理与行动选择 → 可见/可听证据 → 结束与承接
```

按任务与反应进程分配时间，不机械等分；没有情绪转折的段落可以持续同一状态。只有剧情支持情绪弧线时，才设计加压、裂痕和新状态。

### 4.2 不要情绪跳变

真实顺序通常是：

**愤怒维持 → 保护层裂开 → 声音破裂 → 悲伤出现。**

不要写“从愤怒突然转为悲伤”，那会得到面具切换。每段之间写出过渡证据：声音、眼神、呼吸、身体。

#### 4.2.1 保护层是什么

保护层不是情绪，是人物用来“不让底层情绪出来”的**战术**：

- 愤怒：用“我是对的/你是错的”挡住受伤。
- 礼貌/专业：用“我没事/我们按流程来”挡住崩溃。
- 否认：用“我不在乎/这不算什么”挡住失落。
- 照顾对方：用“先处理你”挡住自己的痛。
- 幽默/打岔：用玩笑挡住沉重。
- 控制：用“声音稳、不眨眼、不动”挡住颤抖。
- 忙碌：用“继续做事”挡住停下来。
- 指责：用“都怪你”挡住自己的责任。
- 讲道理：用分析挡住感受。

保护层必须是一个**可演的动作/策略**，不是“她很坚强”这种形容词。

#### 4.2.2 底层情绪/真相

保护层挡住的不是“一个情绪词”，而是**一个她不能面对的事实或需要**：被抛弃、不被爱、做错了、留不住、需要对方、害怕一个人。写清楚“如果层破了，她会失去什么”。

#### 4.2.3 五步设计

1. **立层**：开场 1–2 拍，人物用保护层维持自己。写清她具体在做什么（攻击、礼貌、照顾、开玩笑、控制呼吸）。
2. **加压**：对方的话/事实/动作压上来。压力要升级，不是重复。
3. **裂缝**：每次压力后，人物先**重申保护层**（更用力地攻击/更礼貌/更忙），然后**泄露**一点（声音抖、吸气、目光躲、手指紧、吞咽）。重申越用力，泄露越明显。
4. **失效**：最后一次压力，她无法重申；泄露变成主状态（声音破裂、句子断掉、眼泪/沉默）。但即使失效，她可能还在控制（压回哭腔、转身、擦掉眼泪）。
5. **新状态**：层破之后，人物进入一个新状态：沉默、低声请求、承认、离开、崩溃后的空白。不是回到开场，也不是“彻底释然”。

#### 4.2.4 时间分布

- 每条裂缝占一个时间窗；裂缝之间的间隔越来越短。
- 重申保护层的时间越来越短，泄露的时间越来越长。
- 不要第一拍就破；也不要最后一拍才加压。
- 30 秒文戏可以是：0–6 立层/加压；6–12 第一道裂缝；12–18 第二道裂缝；18–24 失效；24–30 新状态。具体按戏调整。

#### 4.2.5 写证据

每条裂缝写五类证据：

- **声音**：音量、语速、音高、气口、破音、尾音。
- **眼神**：看/不看、看哪里、看多久、什么时候移开。
- **呼吸**：吸气的深浅、停顿、吞咽。
- **身体**：手指、下颌、肩膀、重心、支撑。
- **语言**：重复、改口、断句、说不下去。

#### 4.2.6 检查

- 人物有没有直接“演”底层情绪？有 → 退回保护层。
- 情绪有没有跳变？有 → 加一道裂缝。
- 保护层破得太早？→ 加一次重申。
- 破得太晚？→ 减少裂缝或加大压力。
- 失效后有没有“新状态”？没有 → 补结尾。
- 是不是“愤怒和哭同时端上来”？是 → 把哭延后到裂缝之后。

#### 4.2.7 模板

```text
保护层设计卡
- 保护层（他做什么来挡住情绪）：
- 底层情绪/真相（他不能面对什么）：
- 代价（层破了会失去什么）：
- 压力源（谁/哪句话/哪个动作）：
- 裂缝 1：触发 → 重申 → 泄露 → 代价
- 裂缝 2：...
- 裂缝 3：...
- 失效：触发 → 无法重申 → 泄露成为主状态 → 新状态
- 时间窗：每条裂缝几秒；间隔怎么缩短
- 证据：声音/眼神/呼吸/身体/语言
- 禁止：直接演底层情绪；一次跳变；层破太早/太晚；愤怒和哭同时出现
```

### 4.3 禁止提前反应

每个节拍必填“哪些情绪不能提前出现”：

- 秘密还没落地，不能先哭。
- 对方还没说完，不能先释然。
- 安慰还没被接受，不能先笑。
- 枪还没放下，不能先松肩。

禁止项是节拍的门槛，不是越长越好；只写当前风险。

## 5. 面部与微表情

### 5.1 自然语言先行

先写人话能看见的动作：眉心聚拢、下唇轻微颤抖、下颌绷紧、张嘴想说话却没有声音、眼眶湿润但眼泪不落。需要时再加 AU。

### 5.2 肌肉链

把情绪拆成肌肉的即时运动，而不是情绪结果：

- 错误：“她露出伤心的表情。”
- 脚本方法：“眉心聚拢，挤出两道浅浅竖纹”→“下唇出现振幅不足一毫米的极细微颤抖”→“眉心缓缓舒展，某种东西彻底熄灭后的平坦”。

情绪链的肌肉解构可以是：皱眉肌收缩 → 口轮匝肌失控 → 额肌放松。提示词要像解剖清单，但**只选关键肌肉，不堆全身**。

### 5.3 不对称与矛盾共存

AI 感的一大来源是表情过度对称、过度完成。人类真实情绪从不纯粹：

- **不对称**：“嘴角向左侧微扯，扯出一个只有半弧的不完整苦笑，未扩散至面部其他区域，全然没有抵达眼底。”只动一侧嘴角，明确禁止眼部参与。
- **矛盾共存**：下眼睑保持微红湿润的同时，瞳孔收缩、眼神变锐利；标注“同时发生”或“0.5 秒内转换”。

矛盾必须有依据，不是每个镜头都塞矛盾。

### 5.4 克制、中断、留白

- 不要只写“流泪”，写“眼眶泛红但泪液在眼睑边缘被强行锁住，下眼睑肌肉紧绷颤动”。
- 不要写“摇头否认”，写“摇头动作启动后在第 10 度突然减速停止，如同记起某事”。
- 不要每秒都塞变化；用稀疏、克制的动作放大张力，让“什么都没发生”的片刻成为情绪回响的空间。

### 5.5 量化

数字是精度工具，不是模型保证：

- 幅度：双肩内收 2–3 厘米；唇角下沉半度；颤抖振幅不足一毫米。
- 速度：眼睑抬升先快后慢，完全睁开前有 0.2 秒卡顿。
- 时间：动作耗时 1.5 秒；重叠 0.2 秒；迟滞 0.1–0.3 秒。

只在必要处用；不默认亚毫米、角度、瞳孔参数；不承诺逐帧执行。

### 5.6 onset / apex / offset

表情不是第一帧拉满：

- **onset**：动作开始，肌肉逐渐收缩。
- **apex**：峰值，但可以有控制/受阻。
- **offset**：消退，留下余波。

愤怒例子：开口前压紧嘴唇、咬住下颌、眉毛下压；前半句低沉；触发词处鼻翼张开、身体前探、AU 25/26 快速增强；最后一個词结束立即闭嘴，重新控制。

### 5.7 AU 可选校准

常用：

| AU | 动作 | 用法 |
|---|---|---|
| 01 | 眉内侧上提 | 悲伤、恳求、担忧 |
| 04 | 眉毛下压 | 愤怒、专注、压迫 |
| 05 | 上眼睑上提 | 惊讶、警觉 |
| 07 | 眼睑收紧 | 愤怒、强忍 |
| 15 | 嘴角下拉 | 悲伤、厌恶 |
| 17 | 下巴上提/颏肌收紧 | 强忍、倔强 |
| 23 | 嘴唇收紧 | 压住话 |
| 25 | 双唇分开 | 欲言又止、爆发前 |
| 26 | 下颌张开 | 爆发、惊讶 |
| 31 | 咬紧牙关 | 强忍 |
| 80 | 吞咽 | 压回情绪 |

强度 A–E：A 微弱可察，E 接近极限。AU 不是情绪公式：AU 04 配咬牙前倾接近愤怒，配眉内侧抬起、目光下落则可能是痛苦。组合语境比编号重要。不要只堆编码；模型不一定稳定解析所有 AU。完整表见 [au-reference](au-reference.md)。

### 5.8 人脸约束与情绪错位

- 每个镜头起始可强调“严格遵循上传图片中的五官结构”，保留皮肤质感、细纹、瑕疵，不做磨皮。
- 情绪只能改变微表情、呼吸、肌肉张力、局部汗意；脸型、年龄、肤色、发型、服装、配饰不得漂移。
- 情绪错位：“强迫自己微笑，但眼神空洞，泛着泪光”；“眼神向下躲闪，咬紧牙关，面部肌肉因强忍悲痛而微微颤抖”，配合吞咽、沉重呼吸。

### 5.9 四类证据

写悲伤/愤怒时，用四类证据检查：

- **方向**：眉毛向上、嘴角向下。
- **速度**：缓慢发生，不是瞬间切换。
- **抑制**：想说话，但没有发声；想哭，但泪不落。
- **禁止**：眼泪暂时不能落下；不能先笑。

## 6. 台词、话权与声音

**对白暗流编排。** AI 对白显得假，往往因为太完整、太准确、太有秩序：一个人说完，另一个人准时开口；每句话都表达准确，每种情绪都交代清楚。真实的人被情绪击中后，往往说不完一句完整的话——会停顿、口吃、哽咽、改口，甚至抢对方的话。这一节的目标不是把台词写漂亮，而是让人物把一句话说坏。

**底层判断：**语言想继续，情绪却堵住出口。口吃、重复、沉默、自我修正只是不同的外显结果。AI 演员像人，不是因为他会哭，而是因为他表现出有些话说不出口。真实对白不是整齐轮流；偶尔的失序带来真实。

### 6.1 话轮先于台词

先设计话轮：现在谁拥有话语权，谁准备接话，谁突然抢进来，最后谁退让。不要默认 A 说完 B 再说。

- 一方未说完，另一方温和抢入。
- 有人想插话却插不进。
- 声音短暂重叠后有人退让。

### 6.2 重叠与音量

不要只写“男人说完女人说”。写：

- 男人最后一个词的口型还停着，女人提前 0.1 秒进入。
- 两人声音重叠约 0.2 秒。
- 男人不能突然静音；女人先保持较低音量。
- 谁覆盖谁、谁先收住、谁接管主要声音。

### 6.3 抢话 vs 沉默

- **抢话**：我知道你要说什么，所以必须在它落地前截住。
- **触发词**：抢话要有一个对方无法容忍的词/句（如“你就不管我了吗”里的“不管”）。没有触发词，不要抢；有触发词，才抢。
- **沉默**：我暂时找不到一种方式，让这句话不要继续伤人。
- 刚听到需要消化的秘密，不要抢话，应该停顿；下一步不是“谁接台词”，而是“谁还能承受这句话”。
- 所有地方都抢，会把悲伤演成菜市场。

### 6.4 语言受阻四类

专业上叫 **speech disfluency（言语流失/语言不流畅）**：语言想继续，情绪堵住出口；口吃、重复、沉默、自我修正只是不同的外显结果。

先问：**人物此刻做不到什么？** 不是随手加“口吃”。心理障碍决定语言用哪一种方式失败。

| 心理状态 | 适合的语言失败 |
|---|---|
| 羞耻、内疚、不敢承认自己 | 启动失败/口吃：口型先形成，声音堵在喉咙；失败吸气 |
| 被错误定义、急于自证 | 重复和重音：“我不是，我不是，我不是” |
| 突然听懂残酷的事、无法继续 | 沉默 |
| 想隐藏真实意图 | 说到一半改口/自我修正 |

口吃要落在人物最难面对的词上（中文如“你”“但是”“我”、对方的名字），不要平均分布，否则容易变成喜剧口吃。

例：他不是冷漠，也不是压着怒，而是悲伤超过身体承受范围，只能用礼貌、否认和照顾对方来避免当场崩溃。他想说完每句话，却总在“我”这个字上卡住：嘴唇先形成“我”的口型，出现无声气流或一次失败的吸气；喉结轻动，随后吞咽或改句。“我——”启动即停；“而且我——”短促吸气失败；第二个“我”堵在喉咙里，张嘴无声。停顿必须像人物在寻找语言，不是画面卡顿。

### 6.5 语言恢复

被触发词击中后，人物可能失去完整语言；但当他转到“保护对方/减轻对方罪恶感”时，语言会短暂恢复完整。恢复不等于痛苦消失，而是关系目标暂时压过了自我保护。

例子（中文改写）：

- 她说：“你就不管我了吗？”——触发他的内疚，他开始重复：“我没有，我没有。”
- 她说：“是我拖累了你。”——触发她的罪恶感，他反而恢复完整句子：“不是你拖累我。”
- 完整句子回来，不是因为他好了，而是因为他必须先让她知道：这不是她的错。

### 6.6 语气动线

给人物一条语气弧线，每一步都有事件触发。例子：

公事公办（冷漠）→ 急切温和（关心）→ 强作镇定（伪装）→ 严厉审视 → 疲惫失望 → 硬邦邦隐忍心痛 → 微弱虚无。

写法：语速、重音、气口、连读各有作用；不是每句都加技巧。

### 6.7 方言、口头禅、破碎台词

- 方言/母语/口头禅能绕开 AI 最擅长的标准语言，增加“人味儿”。
- 台词破碎化：颤抖的短句、重复、被中断的犹豫。
- 边界：只在原稿已有或用户允许时新增有声重复、改口、删断句；原稿已有的不完整句必须保留，不能自动补全。

### 6.8 呼吸、停顿、气口

- 停顿不是没有表演，而是人物心里的声音暂时超过了嘴里的声音。
- 每句之间可以留 0.2–0.7 秒不规则空气；不要话赶话。
- 吸气、吞咽、呼气要能和口型/发声兼容；不能同时指令“深吸气”和“连续清晰说话”。

### 6.9 口型与说话兼容

- 口型准确但用力过度会假；用日常聊天幅度，放松下颌，自然连读。
- 重音交给语调和停顿，不按每个重音放大口型。
- 口吃、哽咽、抢话要同时发生在呼吸和口型上，不能只写重复字。

## 7. 身体、小动作与道具

### 7.1 身体动作链

写清：支撑、重心、接触、承重、释放、惯性、结束落点。人物起身、坐下、持物、走路，都要有物理依据。

### 7.2 小动作

小动作不是填充画面，是内心外化的“泄露”：揉眉心、捂住嘴鼻、整理手套、调整重心、拇指顺毛。每个动作要有心理依据和触发点。

### 7.3 道具

道具可以承载人物状态：两杯冰美式，一杯几乎没动，一杯已经融化；婚戒、衣领、打火机、猫。写道具的数量、材质、状态、历史痕迹和变化。

人物丰满度见 [08-character](08-character.md) §1；物件交互见 §2。

### 7.4 连续性

姿势、持物、湿润程度、未完成反应跨镜继承；对白停下，呼吸、衣料声、环境声继续。

## 8. 无台词与听者

### 8.1 听者也有任务

一个人说话时，另外的人在呼吸、整理手套、调整重心、转移视线。听者的任务要具体：判断对方是不是认真、等一个笑点、保护气氛、准备接话、忍住反驳。

### 8.2 无台词的推进

用已有的注意对象、非语言刺激或持续任务推进，按 §2.8 写清处理过程；注视对象和转头顺序本身不足以解释人物的判断。不要擅自加旁白、BGM、吸烟等新事件。

有画外旁白时，分别设计旁白声线/气口与画内人物的感知/呼吸/动作。人物未听见的旁白不作为画内反应的触发词；无现场对白不免除其他适用表演维度，也不强制添加可闻呼吸或面部变化。

### 8.3 错峰反应

多人看画外现场时，不要同时反应：

- B 先失去笑意；
- C 先停止眼球扫描；
- A 最慢，只出现下眼睑张力、咬肌收紧、吞咽、呼吸停顿。

### 8.4 动作密度

不是每秒都塞满变化；稀疏、克制的动作能放大张力。让“什么都没有发生”的片刻成为情绪回响的空间。

### 8.5 无台词不等于绝对静音

保留原有声音边界：呼吸、环境声、衣料声、远处车流。不要因为“无台词”就加音乐或旁白。

## 9. 禁止提前反应

**事件前状态**：人物必须先在自己的目的里——赶时间、端稳箱子、找东西、继续走路——事件是打断，不是预告。先理解每个人此刻的目的和注意力，再设计事件：他在追求什么？注意力在什么上？因此没在看什么？信息差是什么？

每个节拍写“禁止提前发生什么”：

- 秘密还没落地，不能先哭。
- 对方还没说完，不能先释然。
- 安慰还没被接受，不能先笑。
- 枪还没放下，不能先松肩。
- 道歉还没说出口，不能先原谅自己。
- 意外的事件：接触前不能对视、不能提前缩肩、不能提前减速、不能提前让物件倾斜。

禁止项要与触发点绑定；只写当前风险，不堆长清单。

## 10. 常见失败

| 错误 | 症状 | 修复 |
|---|---|---|
| 从一句台词建任务 | 整场戏的任务只围绕一句 | 先读全稿，再建 task |
| 把主题当人物任务 | 角色在“演原生家庭的伤” | 改写成他此刻对对手做什么 |
| 场景共同方向 = 人物个人目标 | 所有人演同一个抽象目标 | 分开共享方向与个人战斗 |
| 用表情编排代替任务 | “眉毛抬起、嘴角颤抖”但没有目的 | 先补 task，再写证据 |
| 情绪形容词当指令 | “悲伤地说”“愤怒地咆哮” | 改写成可见过程与触发 |
| 情绪跳变 | 愤怒直接切悲伤 | 加保护层裂开、声音破裂的过渡 |
| 每镜都塞满 | 眉毛嘴角双手同时动 | 每拍一个主要变化，控制密度 |
| 肌肉清单/数值堆叠 | 一堆 AU 和毫米数 | 只选关键处，自然语言先行 |
| 口吃平均分布 | 每个难词都结巴 | 落在最难面对的词，其他保持流畅 |
| 无台词加旁白/BGM | 静默场景硬加解释 | 保留环境声、呼吸、动作 |
| 远景加近景细节 | 远全景写瞳孔/泪膜 | 按景别分配细节 |
| 人物扁平 | 只有功能台词，没有想要/怕/不能说 | 用 [08-character](08-character.md) §1 的丰满度检查，挖文本、加 1–2 个细节 |
| 物件事件无反应 | 杯子掉了，人物继续念台词 | 写事件前/中/后、第一眼、社会管理、新状态 |

## 11. 示例

### 11.1 悲伤：从情绪标签到可见证据

不要写：“女人非常悲伤，眼泪止不住流下来。”

改写：

> 她眉毛内侧缓慢抬起，嘴角轻微下沉，下巴开始绷紧。她张开嘴想继续说话，却没有立刻发出声音。眼眶逐渐湿润，但眼泪暂时不能落下。辅助：AU 01、15、17，轻度。

四类证据：方向（眉上、嘴角下）、速度（缓慢）、抑制（想说话没声）、禁止（眼泪暂时不落）。

### 11.2 愤怒：发生顺序

不要写：“男人愤怒地大声咆哮。”

改写：

> 开口前，他先压紧嘴唇，咬住下颌，眉毛向内下压。前半句保持低沉。说到“你根本不懂”时，鼻翼张开，身体向前探出，AU 25、26 快速增强。音量短促抬高，最后一个词结束后，他立马闭嘴，重新控制。

顺序：开口前 → 前半句 → 触发词 → 结束后。

### 11.3 对白暗流：话轮、抢话、语言恢复

中文改写（来源：对白暗流篇英文原例，教学改写）：

> 她说：“你就不管我了吗？”——他听到“不管”时，最后一个词的口型还停着，提前 0.1 秒进入：“我没有——”两人的声音重叠约 0.2 秒；他先保持较低音量，等她尾音落下才接管。她接着说：“是我拖累了你。”——他停住，喉结滚动，吞咽，然后恢复完整句子：“不是你拖累我。”完整句子回来，不是痛苦消失，而是他必须先让她知道：这不是她的错。

检查：声音有没有真正重叠；口吃/停顿有没有同时发生在呼吸和口型上；切镜后情绪有没有接住。

### 11.4 老夫妇：潜台词写成反应

来源：9 节整理稿 §9 案例一（可灵），教学改写，非本项目实测。

- 丈夫问：“还会选我吗？”——他真正想被确认；问完看着妻子，等待。
- 妻子提起旧事——她希望自己的感受被听见；笑意淡下来，语气认真，目光仍柔和。
- 丈夫准备继续解释，嘴唇稍开又合上，目光短暂下落，停半拍，再看向她。
- 每镜只推进一个主要心理变化；镜头切换跟着心理变化走。
- 对白停下，呼吸与微弱火声继续，衣料声随身体调整轻轻出现。

逐镜检查：他听见了什么？这句话改变了什么？观众能从哪个反应看出来？

## 12. 可选：双人反差轴

双人戏可以建立在镜像的 +/− 上，但这是人物设计工具，不是八维必填。

- 每人一个 + 和一个 −，相对对方反转。
- 命名这场戏的 essential axis（观众真正读到的轴）。
- 两人仍然朝同一个场景共同方向走；反差在方向下面，通过战术和眼睛漏出来。
- 表面特质常是反面的疤痕：“不在乎”可能是希望耗尽后的保护。

例子：医生“对公司忠诚（+）/ 对病人 careless（−）”；护工“被收买（−）/ 对病人 caring（+）”。essential axis 是“对病人的照护”；两人都在维持“例行工作”的共同方向，但一个的例行是真的，另一个的例行是盔甲，会裂。
