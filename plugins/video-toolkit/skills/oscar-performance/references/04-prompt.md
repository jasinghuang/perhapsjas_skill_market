# 提示词编译：四层结构、语言、参数与负面约束

## 1. 四层主干

每层只承担一种职责，减少长提示词里的权重冲突。不要把四层写成四段散文；每层都应该是可执行的规则。

### 1.1 全局控制

搭片场，保证演员别变，不负责演戏。

- 时长、画幅、帧率、影像风格。
- 场景、年代、环境、天气。
- 人物长相、年龄、服装、发型、身高、声线的一致性。
- 光线基调和轴线。
- 连续性锁定项：身份、服装、道具、光向、轴线、视线。
- 特殊光影/风格要求。

例子：

```text
生成 30 秒写实电影质感、原生同步对白的家庭剧情短片。
画幅 2.39:1，24fps 观感，轻微 35mm 胶片颗粒。
场景：20 世纪中期美国普通工人家庭的后院门廊。
人物一致性：两人始终保持相同面孔、年龄、服装、发型和站位。
```

### 1.2 人物内核

写“这个人是谁、他真正想完成什么”，不写表情清单。

- 身份、年龄、职业、身体性。
- 声线基准：音色、语速、口音、音量习惯。
- 潜台词：台词表面说什么，底下要什么。
- 私人动机：他为什么用自己的方式推这个方向。
- 不能说出口的东西：他怕什么、瞒什么。
- 矛盾/疤痕：表面特质下面的反面。
- 生活痕迹：习惯、物件、旧伤。
- 情绪方向：从哪到哪，不是单点情绪。
- 真正想完成的目标：可演的动作，不是主题。
- 关系目标：他此刻想对对方做什么。
- 可选：acting task block（场景共同方向 / 动机 / 个人目标 / 障碍 / 战术 / 逐拍）。

例子：

```text
人物内核（丈夫）：50 多岁，习惯用解释来修复关系。声线偏低、语速偏慢。
他真正想要的是被确认“你还会选我吗”；他以为解释清楚就能被确认。
关系目标：让妻子听完，不要转身。
```

### 1.3 时间轴

整段戏的核心。按秒/段写，每段同时写清：

- 镜头/时间段：第几秒到第几秒，哪个镜头。
- 说话人、原句（逐字保留）。
- 触发词：哪句话、哪个词让表情/动作开始变化。
- 可见反应：眉眼、嘴唇、呼吸、身体。
- 动作：走位、手势、持物、接触。
- 重叠：谁提前进入、重叠多久、谁覆盖谁。
- 听者反应：听者在处理什么、准备什么。
- 呼吸/停顿：哪里吸气、哪里停、停多久。
- 禁止提前反应：哪些情绪不能先出现。
- 结束状态：这一段结束时人物在哪里，下一段接什么。
- 物件事件（可选）：事件前/中/后、第一眼、社会管理、新状态。

每小段可以套公式：

```text
时间码 / 镜头 + 说话目标 + 准确台词 + 触发词 + 可见反应 + 声音 + 动作 + 话权变化 + 对方反应 + 禁止提前反应 + 结束状态
```

**镜头层级**：先按镜头分，再在镜头内按时间码/节拍分；不要把时间码写成平铺列表。一个镜头可以含多个节拍，一个反应也可以跨镜。

**台词即表情时间轴（六点）**：

1. 说话前：人物是什么状态，开口前怎么维持自己。
2. 触发：哪句、哪个词击中他。
3. 声音：哪个词加重，音高/音量/语速怎么变。
4. 眼神与身体：说话时眼睛、嘴唇、身体怎么动。
5. 呼吸与停顿：哪里吸气、哪里停、停多久；停顿里做了什么心理决定。
6. 结束：说完后进入什么状态。

例子：

```text
0–3 秒｜中近景，丈夫在右、妻子在左。
丈夫：“还会选我吗？”（说完看着她，等确认；不笑，不急着补话。）
触发：妻子没有立刻回答。
可见反应：丈夫嘴唇稍开又合上，目光短暂下落，停半拍，再看向她。
禁止：不要先释然，不要先笑。
结束状态：等待被拉长；下一段由妻子接。
```

### 1.4 声音与镜头

把表演放进声音和镜头里，不另起一套叙事。

- 口型：与台词同步；日常幅度，不夸张咬字。
- 方位：谁在画左/画右，声音从哪来。
- 环境声：底噪、混响、画外声。
- 声音景别：谁近、谁远；镜头转向时声场怎么变。
- 切镜连续：动作匹配、J-cut/L-cut、反应镜头、插入镜头。
- 机位/焦点/光影要点：只写与表演耦合的部分。
- 物件声音/接触/重量/连续性：碰倒、拿起、放下、碎裂、液体。
- 明确禁止项：见第 6 节。

例子：

```text
声音：室内低频底噪；壁炉火声持续；对白停下时只留呼吸和火声。
镜头：固定中近景为主；丈夫停顿处极慢推近 5–8 厘米；不切特写，不抽焦。
禁止：不要轮流念稿；不要自动补完被打断的句子；不要把停顿演成冻结。
```

## 2. 组装顺序与模板

### 2.1 创作模式

```text
【全局控制】
时长/画幅/帧率/风格：
场景/年代/环境：
人物一致性：
光线/轴线/连续性：

【人物内核】
人物 A：身份/声线/潜台词/目标/关系目标
人物 B：……

【时间轴】
0–X 秒｜景别/机位：
说话人/原句：
触发词：
可见反应：
动作/走位：
重叠/话权：
听者反应：
呼吸/停顿：
禁止提前反应：
结束状态：

【声音与镜头】
口型/方位/环境声/声音景别：
切镜/机位/焦点/光影：
明确禁止项：
```

### 2.2 修订模式

- 保留原结构、台词、镜头、风格、时长。
- 只改：表演描述本身；与表演直接耦合的冲突；用户点名部分。
- 输出默认是“保留原结构的完整修订稿”；局部请求给“替换段”；用户只要表演层时，给表演层替换段 + 冲突清单。
- 不另起一套四层模板；在原结构里替换对应段落。

### 2.3 诊断模式

- 不输出完整提示词。
- 输出：场景引擎判断、八维检查、最弱一环、最小修复、干净修复、可选第三档。
- 用户要成稿时转修订模式。

## 3. 语言规则

### 3.1 动作化

写“眉心聚拢、下唇颤抖、目光下落”，不写“她很伤心”。

### 3.2 因果化

写“因为女友拍桌起身，摄影机上摇并后撤”，不写“镜头推进”。

### 3.3 可检查

每条指令都能被看到/听到/在文字里核对。写完问：这句话是给演员的动作，还是给观众的结论？如果是结论，改成动作。

### 3.4 去形容词

删“电影感、真实、情绪激烈、氛围感”。用空间、时间、因果、动作、光影规则替代。

### 3.5 量化有度

数字用于接触时机、距离、重叠、必要幅度；不默认亚毫米、嘴角角度、瞳孔参数；不承诺逐帧执行。

### 3.6 先任务，后证据，再 AU

先写人物对对手做什么；再写脸上的可见证据；最后按需加 AU + 强度。不要反过来。

### 3.7 不堆同义词

一个动作只写一次；避免“缓慢、轻轻、微微”叠用。一个情绪只选一个主要证据，不要眉毛、嘴角、双手同时夸张。

### 3.8 不写互相矛盾的锁定

- 不能锁嘴，又要求长句清晰。
- 不能要求站定，又要求走到 10 米外。
- 不能要求逐字清晰，又要求重叠盖住关键字。
- 发现冲突要披露，给可成立的候选。

### 3.9 文本锚

`@image1`、`@audio1` 等只作为文本锚点沿用；不索取对应文件，不推测素材内容。

## 4. 参考图绑定

- 明确每张图提供什么：身份、服装、场景、道具、构图。
- 写“不得漂移”的项：脸型、年龄、肤色、发型、服装、配饰、身高。
- 写“允许变化”的项：微表情、呼吸、肌肉张力、局部汗意、泪膜。
- 例子：

```text
严格遵循 @image1 中的五官结构、脸型、肤色、发型和服装；保留皮肤质感与细纹，不做磨皮。
情绪只能改变微表情、呼吸、肌肉张力和局部汗意；不得改变脸型、年龄、发型、服装和配饰。
```

- 多图时标清顺序和用途；不要混用不同参考图的脸。

## 5. 技术参数库

参数是服务叙事的，不是越专业越好。先给通用写法，再按模型调整。

| 参数 | 常见写法 | 适用/注意 |
|---|---|---|
| 画幅 | 2.39:1 宽银幕；20:9；16:9；9:16 竖屏 | 宽银幕适合双人/空间；竖屏适合口播/单人 |
| 帧率 | 24fps 观感 | 电影感；不要写“高帧慢动作”除非需要 |
| 焦段 | 70–85mm 中长焦；35mm 环境人像；广角 | 中长焦压缩空间、浅景深；广角带环境但易变形 |
| 景深 | 浅景深；背景低 1.5 档 | 焦点是叙事工具；不要让背景全糊到看不懂 |
| 机位高度 | 略低于眼睛；平视；略高 | 略低增加压迫/亲密；略高增加审视/距离 |
| 手持 | 克制手持、轻微呼吸漂移 | 来自人体惯性，不是随机抖动；站定后仍保留轻浮动 |
| 光线 | 柔和光质、高反差光比；伦勃朗光；冷灰阴影；浅金轮廓光 | 写光源动机、方向、色温、光比 |
| 色彩 | 低饱和蓝灰；暗部墨绿/灰紫；肤色冷中性；少量暗酒红 | 写面积/位置/明暗关系，色号只辅助 |
| 颗粒 | 轻微 35mm 胶片颗粒 | 增加质感；不要过量 |

模型适配：

- 不同模型对镜头术语、参数、负面约束的敏感度不同；先给通用写法，再给模型特化备注。
- 不把某一模型的成功参数写成普适保证。
- 如果模型不支持某些参数，保留叙事意图，删掉无效参数。

## 6. 负面约束库

只写当前风险，不堆长清单。按类分组：

### 6.1 空间

- 禁止跨轴、换边、左右关系漂移。
- 禁止人物瞬移、复制、穿模。
- 禁止位置互换。
- 禁止无意义绕拍。

### 6.2 摄影机

- 禁止数字变焦。
- 禁止突然抽焦。
- 禁止镜头穿人。
- 禁止机位瞬移。
- 禁止一镜到底中出现切镜。

### 6.3 人物

- 禁止身份漂移、换脸、五官重生成。
- 禁止服装变化、配饰消失。
- 禁止肢体融合、多手多脚。
- 禁止身高/体型突变。

### 6.4 表演

- 禁止轮流念稿。
- 禁止表情面具、过度对称。
- 禁止持续怒吼。
- 禁止提前哭、提前笑、提前释然。
- 禁止自动补完被打断的句子。
- 禁止把口吃演成机械重复。
- 禁止每镜都塞满表情。

### 6.5 光影

- 禁止光源黏在脸上。
- 禁止人物每转一次头就重新打光。
- 禁止整体偏色。
- 禁止反打后光源位置改变。

### 6.6 物理

- 禁止人物滑行。
- 禁止道具失重。
- 禁止接触不实。
- 禁止衣物穿模。
- 禁止插镜后手/道具瞬移。
- 禁止物件瞬移/重置/复制/穿模/失重。
- 禁止液体/碎片切镜后消失。
- 禁止人物在物件掉落前先反应。

## 7. 输出格式

### 7.1 全量版

理解卡 → 导演阐述 → 场景引擎判断 → 表演节拍表 → 八维记录 → 镜头/声音摘要 → 风险表 → 最终提示词（代码块）→ 未解决冲突/假设。

### 7.2 简版

用户说“只要成稿”时：提示词 + 3–5 条关键理由 + 未解决冲突。

### 7.3 局部修订

替换段 + 冲突清单（哪些地方与表演/连续性冲突，做了最小调整）。

### 7.4 诊断

```text
场景/提示词：<一句话>
场景引擎：Goal / Obstacle / Tactic / Reversal / Value Shift — 逐项判断
八维检查：<落实/弱/缺失>
最弱一环：<只选一个；修它收益最大>
最小修复：<只改这一环，保留用户版本>
干净修复：<完整成立，可偏离原稿>
可选：<只在确实增加价值时给>
```

## 8. 常见失败

| 失败 | 症状 | 修复 |
|---|---|---|
| 四层变四段散文 | 每层都在重复情绪形容词 | 每层只写职责内的规则 |
| 人物内核写成简历 | 年龄职业一大堆，没有目标 | 补“他此刻想对对方做什么” |
| 时间轴只有时间码 | 没有触发、反应、话权 | 加触发词、可见反应、听者反应 |
| 声音与镜头另起叙事 | 镜头写一套，声音写另一套 | 声音跟随镜头和人物距离 |
| 负面约束堆长清单 | 什么都禁，模型无所适从 | 只写当前风险 |
| 参数堆砌 | 焦段/光圈/色号一大串 | 参数服务叙事，不服务炫技 |
| 参考图绑定太弱 | 只写“参考图” | 写死五官/服装/道具，写允许变化项 |
| 锁定互相矛盾 | 锁嘴又要长句清晰 | 披露冲突，给候选 |
| 人物扁平 | 只有功能台词 | 用 [08-character](08-character.md) §1 的丰满度检查，加 1–2 个细节 |
| 物件事件无反应 | 杯子掉了继续念台词 | 写事件前/中/后、第一眼、新状态 |
