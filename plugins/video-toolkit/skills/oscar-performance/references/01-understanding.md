# 前置理解：先看懂整场戏

## 1. 这一阶段要产出什么

在写任何表演指令之前，先产出四样东西：

1. **《场景理解卡》**：任务约束、故事与人物、导演与视听、表演、执行与风险、场景引擎。
2. **一段导演阐述**：这场戏到底在讲什么，观众应该带走什么。
3. **场景引擎五问的判断**：Goal / Obstacle / Tactic / Reversal / Value Shift，每项成立/弱/不适用+理由。
4. **假设与缺口清单**：哪些是明写、哪些是强推断、哪些必须问。

理解卡不是背景资料，它是契约：后面每条表演指令都必须能追溯到卡上的某一栏；追溯不到，就是形容词堆砌。

## 2. 阅读顺序

1. **读全稿**：所有场次、所有人物、所有台词。不要从一句台词开始建任务。
2. **先看结尾**：最后一句/最后一个动作是读整场戏的钥匙。注意双关的收尾台词。
3. **标记锁定项**：用户明确不能改的剧情、台词、人物关系、镜头、风格、参考图、时长、品牌/合规要求。
4. **填理解卡**：七层 + 场景引擎 + 假设缺口。
5. **跑场景引擎五问**：必查，单条 30 秒也要跑。
6. **写导演阐述**：一句话说清这场戏的共同方向和观众落点。

## 3. 七层检查清单

### 3.1 编剧层

- 一句话故事/主题：这场戏在整部片子里解决什么？
- 规定情境：谁、在哪里、何时、什么关系、之前发生了什么。
- 每个人的目标与障碍：他/她这场戏想要什么？谁/什么不让？
- 冲突结构与价值错位：双方各自的立场为什么都成立？
- 潜台词与信息差：台词表面说什么，底下要什么；观众知道什么，人物不知道什么。
- 节拍与转折：从哪开始、在哪转折、在哪结束；戏剧问题是什么。
- 场景共同方向：全场共享、通常不说出口的方向。
- 人物个人目标：每个人自己的战斗，不能等同于共同方向，也不能等同于主题。

### 3.2 导演层

- 导演意图：为什么拍这场戏，核心表达/情绪落点。
- 全片情绪曲线：起伏、高潮、呼吸点。
- 表演风格与克制程度：自然主义/风格化；外放还是内敛；喜剧/正剧/口播。
- 人物权力关系的变化：谁占上风，何时逆转。
- 调度如何改变关系：走位、距离、高低差、遮挡。
- 视觉母题/象征：反复出现的物件、颜色、构图、声音。
- 观众注意力路径：每一刻该看哪里、该知道什么、该感受什么。
- 观众对角色的 before/after 判断（value shift）：开场怎么看他，结尾怎么看他。

### 3.3 摄影层

- 景别递进：远景/全景/中景/近景/特写怎么分配。
- 焦段与景深：广角/长焦、浅景深/深景深。
- 机位高度：平视/略低/略高，为什么。
- 运动语法：固定/手持/横移/推进/后撤/回摇/环绕。
- 光源动机：光从哪里来，为什么。
- 光比与色温：主光/辅光/轮廓光；暖/冷；背景低几档。
- 色彩脚本：主色、辅色、肤色、暗部；颜色落在哪里、占多大面积。
- 构图与留白：主体位置、空间边界、负空间方向。
- 轴线与视线：谁能看谁，屏幕方向怎么映射。

### 3.4 美术造型层

- 空间地理：平面图、出入口、距离、人物活动区域。
- 道具：数量、材质、状态、历史痕迹；它在戏里是障碍/替身/记忆/身份/工具；它会怎么变。
- 服装：材质、磨损、颜色关系、连续性。
- 妆发：细纹、瑕疵、汗、泪、生活痕迹。
- 时间/天气/季节：光线、湿度、温度、声音环境。

### 3.5 声音层

- 环境底噪：室内/室外、远/近、持续/间歇。
- 空间混响：空旷、狭小、硬墙、软装。
- 画外声：谁在画外、声音从哪个方向来。
- 对白空间：说话人离摄影机多远，声音在声场的什么位置。
- 音乐/静默：什么时候有音乐，什么时候只有呼吸和环境声。

### 3.6 剪辑层

- 节奏与镜头时长：快切/长镜头/呼吸点。
- 切点逻辑：动作匹配、J-cut/L-cut、反应镜头、插入镜头。
- 开场与收尾镜头：第一眼给什么，最后一眼留什么。

### 3.7 表演层

- 人物小传与身体性：姿态、步态、习惯动作、呼吸基线、音色。
- 人物的欲望、不能说出口的东西、矛盾/代价、生活痕迹。
- 每个节拍的动作动词：恳求、试探、掩饰、反击、保护、退让。
- 不说话时“听”的行为：听者在处理什么、准备什么、什么时候反应。
- 情绪触发点与生理基线：什么词/事件会击中他；他平时的呼吸、眨眼、吞咽频率。

## 4. 场景级概念

### 4.1 场景共同方向（scene goal）

一场戏有一个共享的、通常不说出口的方向，所有角色都在朝它走。例子：母亲给儿子装箱、一小时后参军——共同方向是“让这次告别不痛，别让彼此带着难过走”。

它不是影片的主题/反转/揭示。角色不演主题；主题是观众从他们的行动里读出来的副产品。

### 4.2 先看结尾，再命名事件

先看这场戏怎么结束，再回头命名它的“事件”。最后一句/最后一个动作是钥匙。注意双关收尾：嘴上说一件事，实际指另一件事。

### 4.3 所有角色在同一个事件里

事件必须包含场上的每个角色，包括沉默的、没有反应的、看似旁观的人。每个人都是同一事件的参与者或镜像。如果有角色站在事件外面，说明事件命名错了。

### 4.4 物理通道

每个角色都要通过一个可见的物理行为去追同一个事件：母亲“照常”装箱、儿子“随便”吃东西、医生“照章办事”、护工“多做一步照护”。不同的行为，同一个事件，同一片地形。

### 4.5 不同的燃料，同一个方向

所有角色朝同一个方向走，但每个人有自己的理由：儿子为了让母亲安心，母亲出于迷信（出门前不掉泪）。同一个向量，不同的燃料——燃料让每个人的表演有区别，但整场戏仍然统一。

## 5. 场景引擎五问（必查）

每个输入都跑这五问；单条 30 秒也要跑，但每项可以只写一行。必查不等于必须“有”：不适用或未出现要写明理由，不能跳过。

### 5.1 Goal（目标）

- 这场戏的主角在争什么？
- 这场戏是不是通向更大目标的因果链？删掉它，链条还成立吗？
- 目标必须可演：是人能去做的事，不是主题。
- 主角可以错在战术，不能错在目标。

判断：**成立 / 弱 / 不适用+理由**。

### 5.2 Obstacle（障碍）

- 什么在威胁这个目标？
- 是“威胁”还是仅仅“代价”？威胁的是当前一步，还是整个目标？
- 说不出真正风险，就是假障碍。

判断：**成立 / 弱 / 假障碍+理由**。假障碍要明确告诉用户，不要用表演去补。

### 5.3 Tactic（战术）

- 障碍逼出了什么动作？
- 这是不是人物在不完全信息下的合理猜测？
- 失败后他知道了什么、下一步怎么变？
- 对表演来说，Tactic 就是 acting task：他对对手做的具体动作。

判断：**成立 / 弱（不是被逼出来的/失败没带回信息）/ 不适用+理由**。

### 5.4 Reversal（反转）

- 哪里反着来？
  - 自己的动作反噬：我为了 A 做的事，反过来破坏 A。
  - 隐藏的 agency 浮现：我以为我在作用的对象，其实一直在作用我。
  - 局势反转：情况朝战术意图的反面走。
- 单场戏没有反转时，写“无反转+理由”，不要硬造；表演也不要假装有一个转折。

判断：**有（形式+位置）/ 无+理由 / 弱（转了但观众判断没变）**。

### 5.5 Value Shift（观众判断变化）

- 观众开场怎么看他、结尾怎么看他？
- 反转有没有改变这个判断？
- 没有 value shift 的反转是无效反转。
- 氛围片/情绪片可以写“判断变化很弱/不适用”，但要说明。

判断：**有（before → after）/ 弱 / 不适用+理由**。

### 5.6 门禁

- 五问每项必须有判断，不能只写“已查”。
- 如果障碍是假的、战术不是被逼出来的、反转无效，先告诉用户结构问题。
- 可以继续写表演提示词，但不能用微表情去补结构，也不能虚构一个反转。
- 单条 30 秒：每项一行即可；没有反转/没有强 value shift 是允许的，写清楚理由。

### 5.7 事件起源与因果链

如果这场戏有一个关键事件（碰撞、发现、爆炸、转身），先理解它的起源，再设计可见证据：

- 事件是什么；
- 每个人物在事件前的目的；
- 每个人的注意力在什么上、因此没在看什么；
- 信息差：谁知道什么、不知道什么；
- 环境条件：空间、声音、遮挡、人群、时间压力；
- 路径为什么在这一刻交叉；
- 触发点是什么；
- 第一次意识到是什么时候，是否已经太晚；
- 反应如何被各自的目的塑造；
- 事件改变了什么、哪个目的重新接管；
- 事件的叙事功能（障碍/反转/催化剂/揭示/生活质感）。

只写“意外”“因为”不算因果；先有目的和起源，才有可见的因果链。

## 7. 锁定项 vs 可创作项

- **锁定项**：用户明确不可改的剧情、台词、人物关系、镜头、风格、参考图、时长、品牌/合规要求。
- **可创作项**：Agent 可以在锁定范围内设计的走位、动作、微表情、气口、光影细节、声音层次。
- 两者必须在理解卡里写清；越界即失败。
- 修订模式默认全部锁定，只改表演描述、与表演直接耦合的冲突、用户点名部分。

## 8. 推断与待问的分界

理解卡允许标注“推断”，但推断不等于暗补。按三层处理：

1. **明写**：原文直接给出——直接采用，不额外加戏。
2. **强推断**：至少两处文本证据相互支持，且不改变“谁想要什么、谁对谁做了什么、关系性质、关键动作、结局走向”——可以推断，但在理解卡标“推断”，交付时用一句话披露。
3. **决定性未知**：会改变人物目标、人物关系、价值错位、关键动作或结局——必须问一个必要的文字问题，不能暗补。

不影响因果的氛围细节（家具颜色、背景路人、天气）可以合理默认，标“默认”，不占用提问额度。

## 9. 从理解卡到下游

- 场景共同方向 / 人物个人目标 / 障碍 / 潜台词 → acting task 与表演节拍的动作动词。
- 场景引擎 Goal/Obstacle/Tactic → 人物目的/障碍/动作动词。
- Reversal → 表演转折点与强度集中处。
- Value Shift → 结尾状态、余波、观众读点。
- 节拍表/情绪曲线 → 表演时间窗与强度变化。
- 视觉语言/景别 → 表演细节的可见层级（远景姿态、中景手势、近景眼神/呼吸）。
- 光线/色彩 → 情绪与空间氛围；反打与移动光比。
- 空间地理/轴线 → 站位、走位、摄影机路线。
- 道具/服装/妆发 → 小动作、连续性、生活痕迹。
- 声音空间 → 对白气口、重叠、画外声。
- 锁定项 → 负面约束与保留边界。
- 假设缺口 → 需要问用户的问题；不能暗补。

## 10. 常见理解缺口

- 只读台词，不读潜台词：把字面意思当人物目的。
- 把主题当人物任务：让角色“演原生家庭的伤”，而不是演他此刻想对对方做什么。
- 场景共同方向与人物个人目标混为一谈：所有人都在演同一个抽象目标，表演没有区别。
- 不看结尾：事件命名错，整场戏的落点也错。
- 忽略沉默的听者：只写说话的人，听者变成背景。
- 忽略道具/光/服装的状态：表演和物理世界脱节，连续性断裂。
- 用推断填决定性缺口：把没依据的前史写成确定指令。
- 把氛围片当失败的类型片：硬加障碍、反转、value shift，反而破坏气质。

## 11. 完整示例：老夫妇深夜对话

来源：9 节整理稿 §9 案例一（可灵），教学改写，非本项目实测。

### 11.1 理解卡（节选）

- **A 任务约束**：30 秒；双人；台词锁定；风格克制写实；结尾锁定。
- **B 场景共同方向**：确认彼此还被选择、还被听见。
  - 丈夫的个人目标：被确认“你还会选我吗”；他的障碍是妻子提起旧事，说明她没被听见。
  - 妻子的个人目标：让自己的感受被听见；她的障碍是丈夫急着解释，而不是先听。
  - 价值错位：丈夫把“解释清楚”当成修复；妻子要的是“你先听见我”。
- **C 导演/视听**：近景保留等待，特写看清迟疑；冷蓝灰夜色 + 壁炉暖光只照部分皮肤/衣料；反打光向改变，壁炉实际位置不变；暗部留衣褶/发丝/墙面。
- **D 表演**：
  - 丈夫的动作动词：解释 → 察觉 → 停半拍 → 目光下落 → 再抬回。
  - 妻子的动作动词：提起旧事 → 笑意淡下来 → 语气认真 → 目光仍柔和。
  - 听的行为：对白停下，呼吸与微弱火声继续；衣料声随身体调整。
- **E 执行与风险**：双人、固定机位/少量反打；台词长度要留呼吸；禁止轮流念稿；禁止眼泪提前落下。
- **F 场景引擎**：
  - Goal：丈夫想被确认；妻子想被听见。成立，是这场戏的因果链。
  - Obstacle：旧事与“急着解释”的惯性。成立，威胁的是“被确认/被听见”。
  - Tactic：丈夫解释、停顿、目光下落再抬回；妻子提旧事、放慢、目光柔和。成立，都是被障碍逼出来的。
  - Reversal：解释没有换来确认，旧事反而浮出；丈夫的战术反噬。成立。
  - Value Shift：观众从“他在敷衍”到“他在求确认”；从“她在翻旧账”到“她只想被听见”。成立。

### 11.2 导演阐述

这不是一场“吵架”，而是一次很轻的确认：两个人都想被对方接住，但一个用解释，一个用旧事。镜头不替他们哭，只在他们停半拍的时候靠近一点。

### 11.3 下游写法

- 丈夫的表演转折点放在 reversal：解释到一半，察觉妻子的笑意淡下去，嘴唇稍开又合上，目光短暂下落，停半拍，再看向她。
- 妻子的表演转折点放在她说旧事之后：笑意淡下来，语气认真，目光仍柔和；不把“旧事”演成控诉。
- 结尾的静止反应承接 value shift：对白停下，呼吸与火声继续；两个人没有再解释，但距离变了。
