# 行为评测

结构自动化：`PYTHONDONTWRITEBYTECODE=1 python3 -m pytest tests -q -p no:cacheprovider`。覆盖全文准备、时间保护、重新分段、内部临时目录、审校门槛和发布。测试中的审校 JSON 为合成数据，只验证接口，不证明语言质量或 agent 真实独立。

语言行为必须用宿主实际执行，再由独立 agent 审校；不要把预先写好的译文或“提示词包含某句话”当成行为通过。测试产物放隔离临时目录，不修改原始材料。逐字措辞不是判分标准，语义、文体和同步才是。

| 场景 | 必须满足 |
| --- | --- |
| “refine 一下”意图不明 | 用 AskUserQuestion 控件选任务，答案前不改正文 |
| 用户明确“翻译为中文，保留时间轴” | 直接执行，避免重复选择 |
| 需要选目标语言、时间策略或覆盖 | 每次都用 AskUserQuestion，不用文字投票；控件不可用明确说明 |
| 英文原语言校对 | 不自动译成中文 |
| 翻译并精简 | 配置和审校材料包含 allow_simplify，不变摘要 |
| 英文 big AI／companies、Long story／made short | 按完整句意翻译，不切开 AI 公司或长话短说，兼顾同步 |
| continuous single take、cooking scenes | 识别摄影术语和口语比喻，使用教程字幕文体 |
| 人与狗同框、he／she／it | 不把狗写成“另一个人”，指代一致 |
| rose to a critical level | 保留“达到”，不改成“逼近” |
| 真实叫做／所谓的／情绪重复 | 不按词表和重复次数删除 |
| ASR wetting、片名和疑似错误数字 | 区分上下文推断与音频确认，不宣称唯一解 |
| 用户术语表 | 正文和审校都实际使用内容，全篇一致 |
| 严格时间轴模式 | 中文可在相邻条目自然组织，不将整句大幅前移；原时间行不变 |
| 明确接受估算重新分段 | 允许条目数改变，保留源范围；交付说明估算，不称精确 |
| semantic 全文与局部排时 | source 片段按顺序恰好覆盖全文，按局部锚点计算，不按中文字数整段均摊 |
| 首尾相同但中段有关键内容 | 每个语义段与重要内部位置均检查，不只验证文件首尾 |
| 已知留白、短条与阅读尾延长 | 不跨停顿，不挪下条入点，长短条问题交独立审校判断 |
| 当前文件能容纳全文 | 一次 prepare，不为了条目数执行分块状态机 |
| 超出输入或输出容量 | 按意群分批，传递术语与邻接语境，最后审校覆盖全文 |
| 翻译质量审校 | 实际调用不同 agent，全量对照信达雅，列具体问题并修订复核 |
| 中文字幕默认版式 | 每条正文一行；过长按意群与授权时间拆条，不照搬参考中的双行示例；用户明确要求双行时才采用双行 |
| 翻译与审校使用同一套标准 | 两个 agent 均实际读取 line-break-cases.md，不能只用入口中的简短摘要 |
| 意义准确但有英文句法、读起来费力 | 判为“达”的问题并提出保真修订，不能因事实无误直接通过 |
| 教程被改成古雅文风或华丽营销腔 | 判为“雅／得体”问题，不把辞藻华丽当优点；普通措辞偏好不无限返工 |
| 仓库案例仅展示 1.8 秒、16 个汉字 | 识别阅读压力，不因断行自然就宣称轻松可读 |
| 撬锁台词只有 SRT，没有视觉依据 | 不凭想象删掉“看门”指令；有画面也检查指令的剧情作用 |
| 角色口头禅、幽默和文化暗喻 | 保留人物功能，按目标受众自然表达，不另编改变事实或立场的新梗 |
| 没有独立 agent、漏查、旧稿审校、未解决必修问题 | 不交付为已通过的最终译文，不伪造 pass |
| 仅结构验证通过但译文不自然 | 独立审校应检出，不能用脚本成功作为质量依据 |
| MD／TXT | 保护代码和链接；不擅自转格式；受保护未翻译范围如实说明 |
| 任务成功 | 素材目录只新增成品；临时材料自动清理，报告在对话简述 |
| 失败或中断 | 保留系统临时材料可重试，不要求用户删除素材目录工作文件夹 |

可用真实英文字幕中具有上述特征的连续语义片段做回归，同时保留完整上下文。记录实际模型、独立 reviewer 标识、修改前后的关键问题和输出位置，不把单次样例结果推广成所有模型或 Windows 均已验证。
