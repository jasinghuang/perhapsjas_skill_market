# 断句与减词案例（影视台词）

"版面"与"动态对等"两条标准（见 SKILL.md"翻译标准"）的正确手感，用台词案例演示。断句总纲：**行尾是自然的思维停顿点**——主谓、动宾、介宾、固定短语尽量留在同一行，绝不把介词、冠词、助词孤立在行尾或下一行行首；切忌按字数机械分行。

## 案例 1：介词短语与宾语不被割裂

台词语境：刑侦片中警官分析嫌疑人动态。原文 *"We found traces of explosive materials inside the warehouse."*，展示 2.6 秒。

机械切分（反面）：

```text
我们在仓库里发现了一些炸药
的痕迹。
```

问题："炸药"与结构助词"的"、核心名词"痕迹"被暴力腰斩，观众视线换行时产生瞬时认知阻滞。

按意群切分（正确）：

```text
我们在仓库内部
发现了炸药残留痕迹。
```

第一行是完整的地点状语，第二行是完整的动宾结构——两行各自构成独立语义单元，扫读效率翻倍。

## 案例 2：连词领起下半句，不吊在行尾

台词语境：剧情片中二人争吵。原文 *"I didn't tell you the truth because I thought you couldn't handle it."*，展示 2.2 秒。

不良断句（反面）：

```text
我之所以没对你说实话是因为
我以为你承受不了。
```

问题：连词"是因为"吊在第一行行尾，上句头重脚轻，下句缺少连贯依托。

合理断句（正确）：

```text
我没对你说实话，
是怕你承受不住。
```

删掉累赘的"之所以"，以主句逗号为界形成自然呼吸停顿；因果引导词"是怕…"直接领起下半句，视线平滑过渡。

## 案例 3：消除口语填充词与冗余副词

台词语境：律政片中证人在法庭上紧张作答。原文 *"Well, to be completely honest with you, I actually really don't remember seeing him there at that specific moment."*，展示 2.0 秒（CPS 硬上限 14 字）。

| 翻译层级 | 文本呈现 | 问题分析 |
| --- | --- | --- |
| 直译全译 | 呃，老实跟你讲，我其实真的不记得在那个特定时刻看到过他。 | 28 个字。观众必须极快速读扫描，完全顾不上看演员表情 |
| 精简优化 | 说实话，我真不记得当时见过他。 | 14 个字。信息点（真实性表态 + 遗忘 + 时间 + 见人）完整无缺，阅读毫无压力 |
| 极限口语 | 说真的，我完全没印象在那见过他。 | 口语质感更强，去掉了书面化的"特定时刻" |

## 案例 4：长从句的"动作化"拆解

台词语境：科幻片技术员通报飞船事故。原文 *"The failure of the cooling system caused the core temperature to rise to a critical level."*，展示 2.3 秒。

名词化直译（反面）：

```text
冷却系统的故障导致了核心温度上升到了临界水平。
```

问题：充斥"的故障导致了…"式被动/名词化欧化句式，语言黏滞，缺乏临场危机感。

动词化拆解（正确）：

```text
冷却系统失效，
核心温度已逼近极限！
```

把带因果引导的长句拆成两个紧凑短促的并列动作短句，观众余光扫视即能领会险情。

## 案例 5：中文 ASR 流水句——先补标点，再按意群断行

台词语境：都市剧中两人电话争吵。ASR 原文（无标点）："我说了多少次了让你别擅自做主你到底有没有把我的话放在心上"，展示 3.4 秒。

机械切分（反面）：

```text
我说了多少次了让你别擅自做主你
到底有没有把我的话放在心上
```

问题：按字数硬切，"做主"与后续宾语被腰斩，"你"孤立在行尾，两行各自读不成句。

正确（补标点 + 意群断行）：

```text
我说了多少次，别擅自做主——
你有没有把我的话放在心上？
```

拆解：一口气流水句实际是两个意群——责备内容（说别做主）+ 责问（放没放在心上）。先在语义层补出标点、找到意群边界，再让行尾落在边界上；顺带删掉冗余的"了"和"到底"，28 字减为 23 字，两行 11+12 梯形平衡。中文场景不涉及翻译，断句方法与案例 1~4 完全通用。
