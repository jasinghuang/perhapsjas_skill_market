# ASR 同音字/错别字对照表

用法：先按 SKILL.md"视频类型自动检测"判定视频类型，再查对应段落；表外可疑词按"同音/近音 + 上下文语境"判断，不孤立套表。同音字的选择、术语的确定都要基于全文语境。

## 通用

- "地域" → "阈值"
- "一笔代过" → "一笔带过"
- "记录" → "纪录"（纪录片语境）
- "连接" → "链接"（网址语境）
- "涉及" → "设计"（设计语境）

## 影视领域

- "试点" → "视点"（point of view）
- "抚痒" → "俯仰"（镜头俯仰运动）
- "更生降" → "跟升降"（镜头运动分类）
- "组合剂" → "组合技"（组合技巧）
- "类工" → "内功"（武术比喻）
- "被设主体" → "被摄主体"（被拍摄的主体）
- "推轨尽头" → "推轨镜头"
- 外文人名：马丁西克赛斯 → 马丁·斯科塞斯、格达尔 → 戈达尔、西区科科 → 希区柯克
- 外文片名：巴黎灵灯 → 巴里·林登

## 科技领域

- "Crawl" → "Cursor"（AI 编程工具）
- "Google fly" → "Google Flights"
