# 表演节拍、情绪控制与关系

核心依据：用户指定的《把唐国强老师的表演法则写进AI提示词》转录稿，重点为目的、原词触发、可见证据、尚不能发生的反应与镜头内子节拍；并结合《对白暗流编排》的泄露、控制、关系目标。保留此前资料中的倾听、留白、身体余波与无台词推进。完整来源在包外层资料中，本文件可独立用于校正。

## 1. 镜头和表演节拍分开

镜头定义摄影机何时切换、主要观察谁；节拍定义人物的目的、策略或控制状态何时变化。镜头不切，人物仍可从反击转为证明、暴露裂缝、失声和坦白；节拍改变也不要求立刻切镜。

精确落点由用户指定时保留；其余优先按原词或事件定位，需要时补近似时间窗。不要强制把30秒均匀分段。主行动清楚即可，不能为“每镜一个变化”抹掉原场景层次，也不能为每秒找动作。

## 2. 八维检查记录

| 维度 | 判断问题 |
|---|---|
| D1 目的与起始状态 | 在向谁争取什么，为什么此刻要行动？开口前怎样维持自己？ |
| D2 触发点 | 是自己说到某词、听到哪个原词，还是看见、触到某事？ |
| D3 情绪与策略过程 | 怎样启动、增强、控制、改变或消退？是否在有意维持？ |
| D4 眼神与面部 | 看向谁、判断什么？可见部位怎样、何时变化？ |
| D5 身体与动作 | 姿态、手、重心、接触、承重和结束落点是否兼容？ |
| D6 台词与声音 | 原词、声线、态度、重音、语速、口型、呼吸和停顿怎样配合？ |
| D7 对手与话权 | 谁说、谁想接、谁退让？听者此刻处理什么？ |
| D8 结束与连续性 | 哪些状态和未完动作留下？哪些反应不能提前发生？ |

八维必须检查，相关项必须落实。内部可用“维度｜判定｜成稿句段或沿用位置／不适用理由／缺失信息”记录，判定为已落实、沿用明确原文、不适用或信息不足。字段名称齐全不等于通过。

单人口播不必有防御层，无台词场景不必有原词，静候答案不必新增外显动作。远景D4不能要求不可见的嘴角细节；静音D6仍要确认不自加声音。原文已清楚的设定可以沿用一次，不重复填满成稿；关键不足则说明，不能编造动机、对手或刺激。

每个节拍先关联人物、镜头观察对象与原有时间窗，再检查八维。子节拍超出镜头边界时，区分下一镜能看见谁、只能听见谁、哪些状态仍在延续；不为解决分析问题自动新增切镜。

## 3. 目的、保护层与变化过程

可用的关系是：目的 → 维持策略 → 刺激 → 控制受到压力 → 泄露或改变策略 → 新状态。例：用质问要求对方正视自己，愤怒先撑住表达；话说到自己时，攻击性松动，声音变轻。不是所有愤怒都掩盖悲伤，也不是所有悲伤都要哭。

原稿涉及坦白、认错或脆弱表达时，还要确认为什么必须此刻说、是什么阻碍说出口。只据已有情境解释，不为每次口播添加创伤史或重大代价。

同时考虑三股力量：

- 生理泄露：呼吸、声音或身体透露控制不住的部分。
- 自我控制：仍在完成句子、避开目光、收住手势，试图维持原来的样子。
- 关系目标：即使难受，仍想保护对方、被听见或让对方留下。

选当前场景有依据的证据，不要求同时眼红、吞咽、抖唇。语言恢复可能只因保护对方的目标暂时变得更迫切，不代表悲伤消失。

## 4. 把原词当时间锚

先读全部台词，确定变化发生在听到某词、自己说出某词，还是句末之后。引用原词作定位，不改字、不随意增加重音。只标关键节点，不逐字配表情。

写作形状：开口前怎样维持 → 原词出现 → 可见与可听变化 → 气口或决定 → 结束状态。

例如原文的“What about my life?”到“What about me?”：前句仍向外追问；中间停顿承担是否说出更脆弱问题的决定；后句更轻，攻击性减弱。停顿有目的，不是为了电影感硬留空，也不是画面冻结。

## 5. 反应时序与细部强度

需要时明确“在听到证据前不提前认错”“此句结束前眼泪仍未落下”“被打断后才停住手势”。这是针对当前场景的时序边界，不是全片禁止哭或静止。

一个动作可有启动、峰值、保持和消退；不要求每次回到中性脸。爆发过后可重新控制，也可留下紧绷、湿润或呼吸余波。局部不完整、半途停住和不对称可表现控制，但必须说明为什么在此刻发生。

精细表演不等于指令多：选可见且提供新信息的部位，按触发顺序组织，避免同一时刻所有肌肉最大用力。需要AU再读 [面部校准](facial-calibration.md)。

## 6. 眼神、倾听与熟悉感

眼神交代对象和判断用途，如确认对方相信了没有、避开追问、看向证据或确认路面。允许自然眨眼和有原因的视线转移，不用灯光补丁代替注意任务。

听者可以评估、压住回应、准备接话、决定不插话。身体静止仍可能在处理信息，不强制每人无台词时都有吞咽等小动作。多人反应先后来自可见可听条件与态度；剧情需要同步时保留，不人为统一或强制错峰。

多年关系可通过听到熟悉话语后的自我修正、无需重复解释的等待、前倾姿势或接触的延续显现。仅据原稿推导，不新增婚戒、皱纹、方言或共同往事。对镜口播以镜头为交流对象，不虚构观众实时点头反馈。

## 7. 无台词与微小落点

独处的对象可以是窗外、手头事务、已有动物或身体感知。原稿只有望海，就不要补具体回忆和身世。按已给刺激推进，如猫在腿上伸展 → 感到接触 → 垂眼 → 调整左手接触 → 轻抚。

不擅加动物动作凑节拍，猫也不是完全冻结的摆件。接触、支撑和另一只手按 [身体与连续性](physical-continuity.md) 继承。一次注意转移即可成为落点，不自动大笑、治愈或彻底释然。

无台词、无旁白、无BGM不等于绝对静音，保留原有海浪、呼吸和接触声；明确静音时服从静音。不得自加解释性独白或音乐。

## 8. 身体余波

心理变化与冷、痛、疲劳、湿衣服等身体条件分别继承。挡雨让注意松开，不等于立刻温暖；点火成功可肩膀略松，余颤仍在。人物能安慰对方时短暂流畅，呼吸或手部张力仍可持续。

变化幅度服从原风格和事件，不把所有场景都压成低声克制，也不把善意写成突然相爱。
