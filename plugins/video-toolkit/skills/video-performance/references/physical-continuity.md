# 身体动作、可见性与连续状态

承接旧版的动作物理、手势、空间、景别、密度与画外时间方法。表演节拍解释为什么动，本文件检查能否完成、看见、接上。

## 1. 身体动作链

**准备或支撑 → 重心和肢体移动 → 接触或承重 → 惯性与反馈 → 结束状态。** 只补容易断裂的环节，不把简单动作扩写成运动学教材。

| 动作 | 优先检查 |
|---|---|
| 起身 | 足部支撑、身体前移、腾出桌椅空间，站起后的落点 |
| 转身 | 视线、头肩、躯干和脚步的协调，不固定成所有动作的统一顺序 |
| 行走与停止 | 步伐承重、路径、减速与站定后的余动 |
| 奔跑 | 落脚推动、摆臂、持物协调与制动空间，避免身体滑行 |
| 拿放 | 物品原位置、接触、握持、移动、承托、释放与持续的新位置 |
| 推拉、阻拦 | 接触对象、方向、施力和对方反馈；未接触不能已经传力 |
| 负重 | 承重侧的姿态、摆动和惯性，不能无故悬浮或换手 |

同一只手不能同时握杯、撑桌并整理衣领。需要换手先交代交接；物品由手转到桌面承托后才能释放。饮水与清晰连续口播分开。动作重叠必须兼容，不靠流畅形容词掩盖互斥。

## 2. 手势不足与过密分别处理

“全程克制、仅一次、小幅、立刻收回、双手固定”叠加可能压掉手势。先清除矛盾限制，让手势承接完整句意：展开选择、补充承接、句意结束后自然回落；不是每个关键词一次抬手。

自然不等于小。按角色、画幅和风格决定幅度；舞台喜剧与推介口播可以大幅，平静倾听可以静止。双手可分工但不能互抢道具或无故换任务。

动作过密时删重复传达同一信息的细节，留下主要行动和必要变化。停顿让上一动作的结果被看见，不能把每秒填满，也不以删到僵直作为自然。

## 3. 空间与多人关系

原稿固定左右、前后、朝向与摄影机活动区域时保持，区分世界左右和画面左右。剧情需要换位时用连续可读路径实现，不把永不换位变成普遍规则。

每个人的行动由自己感知和任务推动，不复制同一套转头与瞪眼。反应先后由位置、声音、视线与态度解释，既不强制同步也不强制错峰。

参考图身份、服装、配饰和道具数量沿用原稿，身份参考与动作任务各承担原有用途，不擅增外形细节。

## 4. 景别与时间预算

远景优先姿态、路径、距离与肩线，中景优先手势、转身和重心，近景才承载眼神、嘴唇和面部变化。不可见的细节应调整为当前镜头可读的行为，不为看见吞咽擅改特写。

粗排动作、台词和停顿并说明估计性质，不按固定每秒字数保证可读性。没有距离就不能承诺某段跑步一定完成；不靠强行加速、跳步或暗删台词满足时长。

允许实读时可测一次，未经授权不调用付费语音。镜头固定却要求持续跟随、站起后仍被原坐姿裁切等冲突需披露，必要时给最小关联调整。

## 5. 跨镜继承

下一镜接上一镜的结束：身体前倾、手指接触、道具握持、服装、视线、眼周湿润、哭腔和未完成动作都不自动复位。心理有变化时，湿冷、疲劳或余颤仍可能持续。

不要求人物永远不能动；需要变化就给原因、路径和经过时间。姿势锁定是连续性要求，不是把生命活动冻结。

## 6. 插镜、遮挡与画外动作

先建立入镜状态，再判断离画期间动作与时间，最后核对再次入镜结果。切到其他对象只能遮住过程，不能让烟、手、衣服或身体瞬移；不自动新增插镜修复问题。

已有持烟、猫插镜、背影吐烟时，核对哪只手和烟的初始位置、离画时间能否容纳抬手吸入和移开、回来时手和另一侧接触如何持续。不因这个案例给其他无台词场景添烟。插镜太短时明说，不能暗延长锁定时长。

## 7. 摄影与物理反馈的必要接口

检查关键部位是否被遮挡、动作是否出画、镜头能否被事件合理触发、摄影机路径是否连续。手持浮动来自持机呼吸或重心时按原风格保留，停止后退位移不必等于画面完全冻结；不强制所有镜头加过冲、迟滞和晃动。

已有反打可使画面光向改变，实际光源位置仍应一致；已有伞遮光或点火时保留其物理反馈，不让光源黏脸。保持原摄影、美术、环境声与调色，不用新增颗粒、反差或肤质变化代替表演校正。
