# 话轮、语言受阻与声音承接

核心依据：用户指定《一个可以完全释放AI演技的提示词公式》的“对白暗流编排”；结合表演节拍与原有口型校正。不把来源中的具体情境写成所有对话的规则。

## 1. 从话语权看一段对话

先读全部对白，判断当前说话者、准备接话者、抢入触发、重叠后让步者和最终话权。角色可以想插话却没能插进，也可以听到重大信息后暂时找不到回应。不要为了“不轮流念稿”把所有地方都改成抢话。

原台词必须按授权保留。舞台独白、清楚讲解或平静轮流对话若符合任务，不强行打碎。

## 2. 抢入必须形成完整过程

按需写：谁听到哪个原词 → 何时进入 → 两声如何短暂共存 → 谁持续或收住 → 谁获得话权 → 被打断者如何反应。

例如“B听见A说到‘没来’，在A后续尾句尚未结束时低声进入；A将原句说完后收住，B完成回应；A原本准备抬起的手停住，转为听”。没有删原句，也不是A突然被静音。

若原稿已要求断在某词，就保留断口，不自动把余句补完。若未允许删字，不能为了更强烈的打断丢弃原句余字。完整清晰与覆盖关键字互相冲突时明说。

0.1秒提前、0.2秒重叠来自来源的示例，只有落点重要时才作为目标，不能逐句套用或承诺模型精确实现。交叠时明确主次与渐变，避免两人同时都“唯一突出”。

## 3. 抢话与沉默的选择

抢入可能是阻止某种定义继续、急于否认或赶在对方退缩前保护对方；沉默可能是在消化消息、找不到说法或选择不伤人。根据上下文推导，不把动机固定一一对应。

停顿期间可以尚未发声、收住动作、观察对方，但不能每次都加吞咽和吸气。保持参与和反应方向，不写成画面卡顿。对方不需要为了等待轮次冻结。

## 4. 语言怎样失败，以及怎样恢复

| 形式 | 先找原因 | 描述重点 |
|---|---|---|
| 启动失败 | 哪个词此刻难以承认或说出？ | 起音准备、无声停住、必要气口、是否重新启动 |
| 重复 | 急于否定、坚持或确认什么？ | 重复原词的用途、重音变化、何时停止 |
| 沉默 | 什么消息暂时无法接住？ | 信息处理、未完成回应、继续倾听 |
| 自我修正 | 为什么收回本来准备说的话？ | 原断口、改变策略及获准的新表达 |
| 恢复完整语言 | 什么目标暂时压过了阻碍？ | 具体触发、完整句的对象和用途、身体余波 |

这些是选择线索，不是症状或情绪的固定对应表。角色原有口吃或语言习惯应保留，不能假定所有不流畅都有当场心理原因。

区分三件事：无声起音准备、获准的有声重复、改写原句。默认可以在台词外说明无声准备与停顿，不新增可听见的音节。用户允许改口时也只改解决问题的部分，不替人物扩写身世。

原文已有“I am—”“I'm not, I'm not, I'm not”等结构时逐字保留，不能润色成完整标准句。原文没有重复时，不能只因人物悲伤就复制三遍“I”。

原稿明确语言受阻时，将其定位在最难面对的具体词或原有断口，不按固定间隔平均分配到每个代词、每句开头。无声启动也需说明口型已经准备、声音暂未出来、气流或换气如何接续；不要只标“结巴”，也不要求每次同时吞咽或失败吸气。

## 5. 三股力量进入声音

生理泄露、控制、关系目标可以同时起作用。人物为说自己的事启动失败，却在对方自责后完整说出安慰句；语言暂时流畅是为了保护对方，不是情绪复原。由触发说明差异，不让他每句随机卡住。

不默认闭嘴憋气、咬紧牙关与清晰长句并行。声音、口型和呼吸必须兼容，吸气不能与同一人的连续发声同时发生。

## 6. 口播、重音与口型

音量、情绪与张嘴幅度分开控制。重音优先由语调、时值或短停顿体现；口型准确同步、日常幅度、下颌放松、自然连读，不锁成嘴唇不动。

停顿放在句意完成、改变策略、处理反馈的位置，不按关键词重复抬手，不每句都失败吸气。清楚顺畅是某些场景的正确表演，不能统一改成结巴。

## 7. 声音跨镜与同时发声分开

J-cut、L-cut只在原稿已有切镜或获准改剪辑时用来承接声音。它们不能代替实际双人声音重叠。一镜到底可以抢话、画外回应，无须新增切镜。

环境底声依照原稿持续，人物气息和衣料声随动作发生，不擅加全片声场或配乐。切镜后继承声线、哭腔、呼吸进度、眼周湿润及身体动作，不能自动归零。

对白归属、声音方位与原稿人物位置对应，画内说话者的口型与发声一致；切到听者时可延续原说话者的画外声，但不能把这段声音绑定到听者嘴上，也不要求听者因听见对白就跟着动嘴。

## 8. 定位修改层

全局一致性、人物内核、时间轴、声音与镜头作为内部检查层，不要求强制输出四段模板。听者被静音改声音衔接，动机不清改人物任务，触发错位改时间轴；修改后检查关联，不同时重写原稿风格、人物和台词。

各层只保留主责信息：全局放已有场景与一致性基准；人物内核放已有声线、说话习惯、潜台词和目的；时间轴放原句、触发、反应、话权与结束状态；声音和镜头放实际衔接与连续约束。基准只写清一次，时间轴描述相对变化，不在多块反复写相反版本。

语气、音量或哭腔改变不等于换声线。人物已有声线基准时按段继承；原稿未设定且用户未要求时，不擅加口音、方言或新的身份特征。成稿仍可沿用用户原格式，不必重排四层。
