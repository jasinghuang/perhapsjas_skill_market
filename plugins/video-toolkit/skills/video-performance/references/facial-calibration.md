# 面部细部与可选AU校准

核心来源为第一份指定转录稿的面部观察、AU辅助与动作开始—峰值—消退方法。原稿附录是整理者补充资料，与视频正文分开看。这里仅收录与校正任务相关的少量动作，不复制完整情绪编码总表。

## 1. 先描述可见动作及用途

先写此刻为了什么、被什么触发，再选能被景别读到的眉眼、嘴唇、颏部、目光或呼吸。补方向、速度、相对强度和过程，避免只写悲伤或只列编码。

只要本次确实设计了可见面部变化，就必须能回答四问：哪里动、往哪里动、相对有多强、被哪个原词或事件触发；并交代是突然还是逐渐发生。已在同句表达的内容不重复列清单，原文未变或远景看不到的部位不强加细节。

例如“说到‘我’时，下唇准备发音却没有立即出声；短暂停顿后继续原句，颏部的紧绷仍在”。不是把眼红、皱眉、鼻翼、嘴角、吞咽全部同时打开。

动作可有启动、增强、短暂峰值与消退；消退不一定回到中性脸。原稿指定某反应不得提前出现时，用触发限定，不把全片锁成不能哭、不能笑。

## 2. 何时使用AU

用户明确要求、原稿已有编码，或近景细部仍有歧义时，才考虑少量辅助标注。先给自然语言，再给对应编号和可读强度；无需每段都有，也不承诺Seedance按编号精确执行。

FACS用动作单元描述可见面部运动。动作编码和情绪解释是两步，不把编号组合当成必然情绪结果。[Paul Ekman Group：FACS说明](https://www.paulekman.com/facial-action-coding-system/)

## 3. 常用动作的简要对应

| AU | 可读描述 |
|---|---|
| 1 | 眉内侧上提 |
| 4 | 眉毛向下并向内收拢 |
| 7 | 眼睑收紧 |
| 15 | 嘴角下拉 |
| 17 | 颏部隆起上推，伴下唇上推的局部动作 |
| 23 | 嘴唇收紧 |
| 25 | 双唇分开 |
| 26 | 下颌放低、张开 |

以上只作简化动作名称和方向对照，不构成完整FACS评分标准；AU17不等于抬头，AU25/26不要求每个重音都夸张张嘴。对照来源：[CVPR 2021论文作者补充材料](https://openaccess.thecvf.com/content/CVPR2021/supplemental/Yang_Exploiting_Semantic_Embedding_CVPR_2021_supplemental.pdf)。

## 4. 强度和说话兼容

成稿优先用“轻微、逐渐明显、短促增强、随后减弱”等可读描述。原文已有A—E强度时保留其意图，不擅自转换为角度或毫米。强度后缀与侧别修饰不能混写；未核实的编码不猜，回到自然语言。

说话时口唇和下颌需要活动。嘴唇全程紧闭、牙关全程咬死与连续清晰长句可能冲突，允许开口前压紧、触发后释放、句末收住。吸气与连续发声也要分开。

情绪重音不等于AU25/26一直增强。日常口播保留同步、放松下颌和自然连读，不把细部校准变成夸张咬字。

## 5. 边界与核查范围

本版只核对上述常用动作方向及FACS基本用途，未认证整理者附录中的全部肌肉名称、侧别、行为码或情绪组合。原文完整归档，不把未经核实的条目升级为运行规则。

不默认亚毫米颤抖、嘴角半度、强制瞳孔收缩或逐帧肌肉执行；必要的具体参数可作为用户创作目标保留，但不声称模型必然做到。远景不堆面部编码，也不擅自改景别。
