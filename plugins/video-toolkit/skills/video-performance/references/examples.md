# 校正案例

以下均为本版新编教学示例，不是用户提供的完整生成提示词，也没有视频实测。用户资料中的案例另见项目资料目录。示例只展示必要的替换范围，不是通用表情模板。

## A. 边走边说：手势被限制压掉，口型过度用力

**输入**

> 8秒，腰部以上，女主持人向前走，摄影机稳定后退。台词：“两种办法都可以，你先选适合自己的。”全程克制，双手贴身，每句只能做一次很小的手势，马上收回。每个字咬清楚，重音时张大嘴。

**原因**：固定双手和连续限幅压缩了动作空间；强调被错误地绑定到嘴部幅度。

**替换稿**

```text
8秒，腰部以上，人物向前走，摄影机稳定后退。
台词：“两种办法都可以，你先选适合自己的。”
她对镜头介绍两种选择，双手在腰胸之间的可见范围承接完整句意：说“两种办法”时，双手向身体两侧的相邻区域展开，呈现两种选择；转入“你先选适合自己的”时，一只手承接为朝向镜头的开放掌心，另一只自然回落，句意结束后手势随之落下。手势与步伐协调，不按单字重复抬手。
口型与原台词同步，以日常交谈的幅度清晰连读，下颌放松；“适合自己”的强调交给语调与时值，视线主要与镜头交流并兼顾脚下路径。
```

## B. 双人争执：情绪面具与倾听待机

**输入**

> 10秒，固定双人中景，甲左乙右，隔桌坐着。甲愤怒地说：“我等了你两个小时。”乙轮到自己才启动，伤心地说：“我知道。”两人一直握拳、皱眉、抖嘴唇。

**原因**：多项重复面部指令争抢注意力，反应被说话轮次代替，等待没有内容。

**替换稿**

```text
10秒，固定双人中景，甲左乙右，隔桌坐着。
甲试图让乙正面承认失约，说：“我等了你两个小时。”说到等待的时长时，原本放在桌边的手向乙推进少许，句末停住，等乙看向自己。
乙在甲说话时听着，原先准备解释的手势启动后收住，先看向甲停在桌边的手，再回到甲脸上。短暂停顿后说：“我知道。”乙把手放回自己一侧，保持面对甲，等待下一句；甲听完没有马上接话，观察乙是否还会解释。
```

## C. 多人反应：有原因的先后，不套固定延迟

**输入**

> 6秒，固定三人中景。A面向门，B侧对门，C背对门。门外传来熟人的声音。三人同一瞬间转头、瞪眼、张嘴。

**替换稿**

```text
6秒，固定三人中景。A面向门，B侧对门，C背对门。门外传来熟人的声音。
A听见声音后先看向门口，认出说话者；B察觉A视线改变，停下原先的回应，顺势转向门口。C先侧头辨认声音，再转动肩身看过去。三人保持原位置，转向由各自获得的信息触发，不统一复制瞪眼与张嘴。
```

不声称门已打开，也不凭空增加门外人物的身份或表情。

## D. 持物起身：接触与结束状态

**输入**

> 8秒，固定全身镜头，桌面一只杯子。她坐在椅子上，右手端杯喝水，同时连续说：“我已经决定了，现在就走。”随后右手撑桌站起，手里的杯子仍然不动。

**原因**：饮水与连续口播、同一只手握杯与撑桌互斥；杯子的结束状态缺失。

**替换稿**

```text
8秒，固定全身镜头，桌面一只杯子。她坐在椅子上，用右手端杯喝一口，放回桌面并松开。杯子留在桌面原来的位置。
她说：“我已经决定了，现在就走。”说完，双脚在地面形成支撑，上身前移，空出的右手撑住桌沿，起身离开椅面，站稳在椅子与桌边之间。
```

原稿没有说明交流对象，修订不增加画外人物。固定镜头能否完整容纳起身，需结合实际构图检查。

## E. 奔跑停步：保持远景，修复滑行

**输入**

> 8秒，全身远景，女人右手提旅行袋跑向路口，在路口停住。她脚不落地，身体平滑前移，旅行袋无重量漂浮。停下时立刻全身冻结。要求表现瞳孔收缩与下唇颤动。

**替换稿**

```text
8秒，全身远景，女人右手提旅行袋跑向路口。每次落脚承重后推动身体向前，左臂配合步伐，右臂随袋子重量保持较小摆动，袋子持续由右手提住。
接近路口时她提前缩短步幅、降低速度，在路口前站稳；袋子在停止后仍有短暂余摆，随后垂落。她保持面向路口，胸背可见跑后的呼吸起伏，用站定后的姿态变化承接紧张，不在远景堆入不可读的面部细节。
```

时长仅作原稿目标，需结合原始距离核对；不能在未知距离时承诺一定跑得完。

## F. 远景告别：不强加近景细节

**输入**

> 6秒，固定远景，不改镜头。她站在门口，听见身后说“别走”，没有回答，最后离开。请加瞳孔变化、泪膜、嘴角下沉半度。

**替换稿**

```text
6秒，固定远景。她站在门口，听见身后说“别走”，迈出的脚步停住，肩身仍朝门外，头稍向声音方向转去，却没有完全回身。她没有回答；短暂停留后把重心移到前脚，继续走出门口。
```

保留原来的沉默与离开；反应由声音触发，以远景读得出的动作完成。

## G. 保留夸张风格，修复不可能动作

**输入**

> 5秒舞台喜剧，中景，固定镜头。台词：“这也太离谱了！”他夸张地张开双臂，同时双手始终紧握胸前的一本书。最后把书举到头顶。

**替换稿**

```text
5秒舞台喜剧，中景，固定镜头。他先将书夹稳在左臂与胸前之间，右臂向外大幅展开，说：“这也太离谱了！”保留舞台化的语气和身体幅度。句末右手收回，与左手共同握住书，再把书举到头顶。
```

此稿保留展开与举书，放宽“始终双手握书”；两项要求不能同时成立，交付时要说明这一取舍。书举到头顶超出原中景时，不擅改镜头；说明最终动作可能出画，按用户优先级选择保留动作或调整构图。

## H. 关系表演：问句之后听见对方

H—J依据补充资料的主题新编，所设台词和镜头不冒充来源中的完整提示词。

**输入**

> 15秒，固定双人中景，老夫妇深夜对话。丈夫问：“还会选我吗？”妻子说：“我那时只是希望你听完。”丈夫想被确认，妻子希望先被听见。丈夫全程急切解释、连续点头。妻子说话时他只等着接下一句。结尾丈夫前倾，认真等她继续。不改台词、镜头和结尾。

**原因**：连续点头和抢着解释没有根据妻子的回应调整，关系意图没有进入倾听过程。

**替换稿**

```text
15秒，固定双人中景，老夫妇深夜对话。丈夫问：“还会选我吗？”问完看着妻子，等待确认。
妻子说：“我那时只是希望你听完。”语气转为认真，仍看着他。丈夫原本准备接话，听到“听完”时收住，短暂垂眼，再回到她脸上；他不再用连续点头催促回答，身体稍向前倾，留出她继续说话的时间。
结尾维持这份前倾与等待，不补新的台词或释然笑容。
```

## I. 身体余波：挡雨不等于立刻温暖

**输入**

> 12秒，固定中景，雨夜便利店外。男人湿冷，低头反复按打火机未成功；女人走近，用伞替他挡住雨。他瞬间停止全部颤抖，立刻抬头灿笑，再点火成功。无台词，保留女人挡雨与点火成功。

**替换稿**

```text
12秒，固定中景，雨夜便利店外。男人湿冷，低头按打火机，失败后拇指停了一下，肩膀仍内收。女人走近，将伞移到能替他挡雨的位置。
男人先察觉落在手上的雨被挡住，暂时停下按动，眼睛移向伞沿，再略抬头看她；短暂停留后看回手里，重新尝试，点火成功。肩膀松开少许，湿冷造成的间歇余颤仍在。他没有突然灿笑，站位与手中打火机保持连续。
无台词。
```

## J. 无台词推进：触到变化才转移注意

**输入**

> 15秒，无台词、无旁白、无BGM。阴天海边室内。镜头1（0—7秒）远景：男人望海，猫睡在腿上，左手搭在猫背，右手放扶手。镜头2（7—10秒）猫与左手特写：猫伸展。镜头3（10—15秒）回原远景：他轻抚猫。现在人物每秒皱眉、吞咽、咬唇，结尾突然大笑，右手瞬移到猫背。请自然一些，不改镜头与两手分工。

**替换稿**

```text

镜头1（0—7秒）远景：男人保持望海，猫睡在腿上，左手搭在猫背，右手放扶手。视线在窗外停留，呼吸自然，不连续堆叠面部动作。
镜头2（7—10秒）猫与左手特写：猫在腿上伸展，左手随背部起伏调整接触，不压住猫的动作。人物保持坐姿，右手仍放扶手。

```

只保持原输入允许的声音边界，不新增解释性对白、音乐或来源其他片段里的吸烟动作。

## K. 一镜多节拍：质问的保护层逐渐松动

K—R为v2.0教学改写，依据两份核心文档设计，不是来源视频的完整原始提示词，也没有视频实测。

**输入**

> 12秒固定近景，女人对男人说：“What about my life? What about me?”前句质问，后句终于说到自己的需要。现在第一帧就哭到最后。保留两句原词；后句前不能落泪，不改镜头。

**替换稿**

```text
12秒固定近景。她在开口前维持直视，试图让男人正视她的处境。说：“What about my life?”声音仍有向外追问的力量，眉间张力随句意增强，句末没有立刻松开。
两句之间短促吸气，目光短暂下落，再看回男人；停顿承担是否说出自己需要的决定。她说：“What about me?”声音更轻、更慢，攻击性减弱，嘴角的紧绷开始松动，眼眶渐湿，但后句前不落泪。
说完仍等待对方回答，呼吸没有完全平复；不切镜，也不在句末自动恢复中性脸。
```

## L. 同一个字出现两次：触发必须定位

**输入**

> 固定近景，台词：“你说是为我好，可你问过我吗？”她一开始反驳，只在后半句第二个“我”上声音第一次破裂。原稿却写第一句开头就哽咽。逐字保留。

**替换稿**

```text
固定近景。她说：“你说是为我好，可你问过我吗？”前半句声音仍完整，试图反驳对方的说法；到“可你问过”时速度放慢，在“问过我吗”的“我”上声音第一次破裂，再把“吗”说完。
嘴部按原词连续发音，不在“为我好”的第一个“我”上提前哽咽；句末维持对对方的注视，等他回答。
```

## M. 抢话：尾句还在，话权逐渐交出

**输入**

> 10秒固定双人中景，一镜到底。A说：“你昨天没来，我一直在等。”B说：“我知道，我会解释。”B听到“没来”就想接话，但A后半句必须完整说完。禁止删字。原稿让A被抢时瞬间静音。

**替换稿**

```text
10秒固定双人中景，一镜到底。
A说：“你昨天没来，我一直在等。”B听见“没来”后准备回应，在A开始“我一直在等”时较低音量进入：“我知道，我会解释。”
两声短暂共存，A仍将原句说完，不被突然静音；A的尾音收住后B成为主要声音，完成解释的承诺。A听着，原本准备继续的动作停住，等待解释。保留全部原词，短暂重叠期间以A尾句清晰为优先。
```

若用户要求交叠部分每字同等突出，应说明声音目标冲突，不能同时承诺两人都是唯一主体。

## N. 重大消息后留出消化，不用抢话填空

**输入**

> 固定双人中景。A说：“我明天就走，不会再回来。”B说：“我知道了。”B第一次知道，原稿却让B在“明天”就抢答，并机械重复三次。保留两句。

**替换稿**

```text
固定双人中景。A说：“我明天就走，不会再回来。”B原本准备回应，听见“不会再回来”后停住，没有抢进剩余台词。A说完仍面对B等待。
B的视线短暂离开，再回到A脸上，像在找一个能接住消息的说法。停顿后说：“我知道了。”只说原句，声音落稳得较慢，身体没有随句末立刻放松。
```

## O. 断句与完整语言：恢复有关系目标

**输入**

> 固定双人中景，顺序与原词锁定：男“I am—”；女“I don't want to torture you.”；男“You're not torturing me.”。男难以谈自己，听到女方自责后要先安慰她。原稿要求三句均匀结巴，并补完首句。

**替换稿**

```text
固定双人中景。男人先说：“I am—”在原有断口收住，没有自动补出余句；他仍在维持面对女人的姿态，准备继续却未发声。
女人说：“I don't want to torture you.”男人听见“torture you”后把注意从自己的困难转向她的自责。女人说完，他说：“You're not torturing me.”这句短暂恢复完整、直接，目光回到她脸上，先减轻她的负担。
说完他的呼吸仍不平稳，手部张力没有全消；语言流畅并不代表痛苦已经解除。
```

## P. AU辅助：细部有过程，说话不锁嘴

**输入**

> 固定近景，台词：“我没怪你。”说“怪”时短促加强，之后重新压住情绪。请保留AU4、AU23、AU25、AU26辅助标注。原稿要求全程嘴唇紧闭、开口幅度最大、每个重音都最大用力。

**替换稿**

```text
固定近景。开口前眉间向内下收，双唇短暂收紧，像在准备把话说稳（AU4、AU23作为辅助）。
他说：“我没怪你。”开口时释放唇部收紧，双唇分开、下颌随发音自然放低（AU25、AU26），不保持闭嘴。说到“怪”时声音短促加强，眉间张力在这里达到本句峰值；随后将“你”说完，嘴部回到休息状态，眉间张力逐渐减弱但未完全消失。
AU标注只辅助对应动作，不把整句保持为最大强度。
```

## Q. 允许重复时只改获准的词

```text
固定双人中景。A自责后，B看向A，较急地说：“不是，不是你的错。”第一个“不是”是立即截住自责的否认，第二个起势较稳，带出完整安慰；句末仍留意A的反应，不继续增加重复或新台词。
```

## R. 顺畅讲解也成立：保留原台词，不为真实加口吃

**输入**

> 8秒中景，对镜温和清楚地说：“先看清规则，再做决定。”不要改字。请自然一些，原稿写每个字都张大嘴、每秒吞咽一次。

**替换稿**

```text
8秒中景，对镜温和清楚地说：“先看清规则，再做决定。”前半句以开放手势邀请观众听清，句意转入“再做决定”时语气放缓，手势自然回落。口型同步、日常交谈幅度，下颌放松，清晰连读；在完整意思之间自然换气，不按秒插入吞咽，也不新增有声重复或口吃。
```

## S. 八维落实到成稿，不只在分析里打勾

**输入**

> 10秒固定双人中景，A右手握杯，想让B听清原因。A说：“你从没问过我。”B说：“不，我在听。”A说到“问过”才第一次放轻，B等A说完回应，结尾A仍握杯看B。原稿只写“伤心地说”。只给成稿。

**替换稿**

```text
10秒固定双人中景。A右手握杯，面向B，试图让B先听清自己的处境。A说：“你从没问过我。”前半句仍试图追问，说到“问过”时声音第一次放轻，原本朝B的注视稍停，句末重新看住B，呼吸留出一个等待回应的间隙；右手始终稳稳握杯，不加摇晃或换手。
B听完才说：“不，我在听。”B面向A，语气放稳，表示愿意让A继续，不抢入A的原句。结尾A仍右手握杯看B，保留尚未把原因讲完的张力，等待对方继续听，没有突然释然或落泪。
```

**输入**

```text
8秒固定远景。男人维持独坐望窗外的姿态与注意，像在继续原本的静候；身体自然承重，视线方向不因时间经过而突然切换。结尾仍坐在原位望窗外，不新增转折或反应事件。全程绝对静音，无对白、旁白、配乐或其他声响。
```
