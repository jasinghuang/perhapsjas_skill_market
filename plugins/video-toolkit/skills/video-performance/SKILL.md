# 视频表演与动作校正

将已有提示词变成有触发、有过程、有对手反馈、能接续的演员行为。独立使用，无其他 skill 依赖，不预设模型版本或最大时长。

## 方法主干

两条主线一起看：**人物自身怎样变化，人物之间怎样互相改变。**

用这条判断关系组织相关表演：

**目的与起始控制 → 具体感知或原词触发 → 变化启动、增强与收住 → 话权和对方反应 → 结束状态与后续继承。**

目的落在人能做的事上，如让对方听完、确认被相信、阻止自责、说清选择。独处时也可以维持注意、避开一个念头或照顾身边事物，不虚构对手或身世。情绪词可说明方向，具体行为负责让变化可读。

两份核心方法分别落实在 [表演节拍](references/performance-beats.md) 和 [对白互动](references/dialogue-interaction.md) 中。细部表演应有原因和时间过程，不因怕过度而一律删掉，也不按词逐项堆肌肉。

## 八维必查与落实

每段纳入校正范围的表演都必须检查以下八维；相关维度必须在成稿或已明确引用的原稿设定中落实，不能只留在分析里。

| 编号 | 必查维度 | 必须确认的内容 |
|---|---|---|
| D1 | 人物目的与起始状态 | 在向谁争取什么，为什么此刻要行动，开场如何维持自己；不虚构身世 |
| D2 | 触发点 | 自己说到、听见或感知什么后变化；同词多次出现要定位到具体位置 |
| D3 | 情绪与策略过程 | 从何处到何处，怎样启动、增强、受到控制或消退；有意维持状态也可成立 |
| D4 | 眼神与面部 | 注视对象与用途；可见变化的部位、方向、相对速度、强度和触发时机 |
| D5 | 身体与动作 | 姿态、手势、支撑、重心、接触与结束落点，动作是否兼容 |
| D6 | 台词与声音 | 原词、声线基准、态度、重音、语速、口型、呼吸和停顿是否配合；遵守静音边界 |
| D7 | 对手与话权 | 听者此刻处理什么、谁准备接话、是否抢入、谁继续或退让；不强制交叠 |
| D8 | 结束与连续性 | 留下什么供下段接续；哪些反应须等触发后才出现；情绪与身体余波是否保留 |

内部逐维判定为“已落实、沿用明确原文、不适用、信息不足”之一，并能对应到具体句段或原因；不能只记“已查、自然、同上”。相关维度缺失时补足最少可执行描述；原文已清楚时保留，不重复加写。

远景不强加面部细节，无对白不加台词，无对手不造对手，无新刺激不造事件；沿用既定姿态或注意也可作为落实。涉及无声场景的D6仍需确认原声音边界。关键缺失会改变原意时明确说明或澄清，不能为填齐八维擅自编造。

八维是检查门槛，不是固定输出八段，也不要求每维每秒变化。局部请求只校正指定段落，用已知上下文检查接口，不扩写全文。AU始终为D4的可选辅助，不是第九个必填项。

## 保留边界

- 读完整稿，保留用户锁定的剧情、人物关系、原词、参考标签、外形、道具、时长、镜头顺序和风格。区分必留条件与用户明确要求修复的错误描述。
- 默认保留台词字词及其相对次序；可在台词外标注语调、气口、起音迟疑与停顿。新增有声重复、音节、口头禅、改口、删断句，或重排台词，需要原稿已有或用户允许。原稿已有重复、未完成句和断句必须保留，不能自动补全润色。
- 话轮交叠可改变起音与覆盖关系，不擅自删字。若用户要求逐字清晰，又要求重叠遮住关键字，说明冲突，给可成立的候选。
- 保留原语言与交付范围。局部请求只改局部；全文修订同步消除冲突旧文，不能在末尾追加相反规则。
- 尊重自然、舞台化、喜剧、口播、爆发等既定风格。自然不等于小幅，真实不等于所有人都哭、口吃、抢话或故意失焦。
- 摄影、光影、配乐和剪辑不自动重做。若妨碍关键动作可见或可完成，披露冲突并给最小关联调整。不自动调用生成服务、上传素材或产生费用。

## 工作流程

### 1. 提取约束，找出问题

先读全场景及所有台词，再判断谁对谁做什么、起始身体与情绪状态、已有触发事件、期望结果、景别和时长。区分用户反馈、文本事实和自己的推测。

优先处理用户点名问题。未见视频时只能说“原稿可能导致”，不能声称看到了成片缺陷。没有原稿时请求原稿；可给标明性质的候选替换段，不冒称完整修订。

信息够用就直接改。非关键缺失不补造背景；决定性约束缺失时提出一个具体问题，并先做不依赖答案的部分。

### 2. 按表演节拍分析，保留镜头结构

情绪或交流策略真正改变时才分节拍。一镜可含多个节拍，一个反应也可跨镜持续；不为分节拍增切镜，不强制等长分段或每秒一个动作。

按八维逐段检查。每个节拍明确对应人物与先后位置；原稿已有镜头、观察对象和时间窗时沿用，子节拍不能越出所属镜头却继续指令该镜头已经看不到的表情。允许反应跨镜，但要分别说明画内行为、画外声与继承状态。原稿无精确时间时不强填数字。

简单任务也检查八维，只是不必输出表格。需要分析记录时，使用 [八维检查记录](references/performance-beats.md)；成稿必须有相关维度的执行依据。

- 有转变、压抑、爆发或关系潜台词：读 [表演节拍](references/performance-beats.md)。
- 有对白、停顿、抢入、重复或语言恢复：读 [对白互动](references/dialogue-interaction.md)。
- 有手势、行走、接触、持物、多人走位或跨镜：读 [身体与连续性](references/physical-continuity.md)。
- 近景细部不足、用户要求AU或原稿已含AU：再读 [面部校准](references/facial-calibration.md)。

### 3. 修复相关层

先找原因，再选择必要变化：

- 抽象情绪：补具体触发与可见过程，保留原来含义，不只换形容词。
- 提前反应：用事件或原词限定出现顺序，如听见秘密后才停顿、声音破裂后才落泪；不默认所有人都必须经历同一顺序。
- 表演过满：删重复信息，安排增强、受到压制和消退，不把自然改成冻结。
- 动作不足：检查“仅一次、小幅、立刻收回、双手固定”等叠加限制，恢复完整语义手势及承接回落。
- 台词朗读感：确定话权、态度、触发词与气口，按情境选停顿、抢入或语言受阻，不机械加入全部技巧。
- 倾听待机：给听者当下的信息处理与回应准备；反应由实际感知触发，不预知后文。
- 身体失真：修复支撑、重心、接触、承重、释放、惯性与结束状态。
- 状态跳变：一次善意或语言恢复不自动消除冷、痛、疲劳或悲伤；跨镜继承姿势、持物、湿润程度和未完成反应。
- 无台词空转：用已有注意对象或非语言刺激推进，保留未解决和未释然，不擅加对白、旁白、BGM或吸烟等新事件。

全局一致性、人物内核、时间轴、声音与镜头是内部定位问题的四层。优先改出问题的一层，再检查关联，不强制将所有原稿改成四层格式。

### 4. 写成可执行描述

把反应绑定到原词或事件，区分“刚听到”“说到”和“说完后”。按需写动作启动、峰值与收住，允许合理并行；不要同时指令吸气和连续发声、端杯喝水和清晰口播。

按景别给信息：远景读姿态、距离与路径，中景读手势和重心，近景再写眼神、嘴唇与呼吸细节。先用人话描述，再按需少量AU校准，不把AU组合当情绪公式或模型接口。

强度由场景决定。数字用于必要的接触时机、距离或重叠目标，不默认亚毫米、嘴角角度和瞳孔参数，不承诺逐帧执行。少量具体禁止项可阻止提前哭、自动补完断句等当前风险，不堆长负面词。

### 5. 通读验收

交付前逐段复核八维：相关项均已有执行依据，沿用项能定位原文，不适用项有情境理由，关键未知没有被暗补。再核对锁定内容与风格、触发先后、身体可行性、时间窗、景别可见性、话轮与声音、跨镜继承、全文矛盾；不能只把维度名称列齐就通过。

逐节拍问：**此刻感知了什么？改变了什么？观众从哪里读到？下一段接住什么？** 有意等待可保留，不强加变化。

时长与动作不能同时满足时明说，先交付成立部分，不靠加速、跳过过程或暗改台词伪造可行稿。

## 交付与验证

默认给少量关键修改理由，再用代码块给可复制修订稿；局部给替换段，全文给消除旧冲突的完整稿。用户只要成稿时直接给成稿，必要假设和未解决冲突简短说明。不默认输出心理长文、节拍表、AU清单或摄影重设计。

方法案例见 [校正案例](references/examples.md)，行为验证见 [验证用例](references/evaluation.md)。文字自检可确认约束与逻辑，不能证明视频自然、实际声音重叠或模型稳定遵循。独立来源、教学案例、文字输出与视频实测分别标识。

视频反馈可读取时，按 [视频复核三项](references/evaluation.md)检查实际声音重叠、语言受阻的声口呼吸配合、切镜后的状态继承；没有视频或音轨就标明未验证，不把文字时间码当成片证据。
